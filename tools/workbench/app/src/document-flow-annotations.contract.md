# Raw Link annotation transport contract

`createAnnotationTransport({mupdf})` injects the existing pinned MuPDF 1.28.1 namespace. This module imports no engine and never opens a URI or executes an action. All work is local, bounded and asynchronous at the byte boundary.

- `inspect({sourceBytes:Uint8Array, sourceSha256})` verifies the exact source hash and returns a frozen, privately issued model with `pageCount` and `annotations`. Each descriptor has original `sourcePageIndex`, original `annotationIndex`, bottom-up PDF `rect`, optional `quadPoints`, fixed `kind`, `eligible`/`reason`, safe destination type/target page and all numeric `internalDestinationSourcePageIndices`. `preservedMissingDestination:true` means the exact source name/alias chain has a complete private proof that its named target is absent; output must retain that absence and the same name. `destinationUnresolved:true` means any nonprovable target still conservatively stops reflow. `actionOwnershipUnsupported:true` marks known action-owned roots outside this proof (annotation AA/PA, page AA, catalog AA/OpenAction). No URI, label, raw action or private field is exposed. JSON reconstruction cannot recreate authority.
- `transport({model,sourceBytes,outputBytes,sourcePageMap,moves,reflowedSourcePages,destinationMoves})` opens a private output copy and returns `{pdf:Uint8Array,report}`. It first verifies that every original annotation still occurs in its source identity page at its original annotation index. `sourcePageMap` must map every original source page once to one distinct, valid output identity page. Generated pages initially carry no annotations. Existing native flow must not delete/recreate original links before this hook.
- Moves contain exactly `{sourcePageIndex,annotationIndex,outputPageIndex,dx,dy}`. Translation is in PDF bottom-up coordinates. One original Link can have only one move, to one output page; its owner source page must be in `reflowedSourcePages`. Same-page shifts are supported. An annotation without a move keeps its original dictionary and its array order.
- The adapter pushes the **existing PDFObject** between localized Annots arrays in the same output document. It changes only Rect, P, and translated QuadPoints. It does not recreate an annotation, whitelist/copy action fields, graft a foreign object, or globally replace an xref. Other keys, nested unknown dictionaries/actions and stream bytes remain attached to their original objects.
- `validate` takes the same inputs and saved output bytes and returns `{ok:true,...}` or `{ok:false,code}`. It independently inventories every original annotation, compares the full semantic graph (including unknown nested keys, shared-reference topology, cycles and raw streams), normalizes all page references by source identity, and checks translated geometry/P. Untouched annotations use an additional full fingerprint including Rect/P/QuadPoints. Dropped/extra/shared annotations, changed actions/streams and changed fixed-edge annotations fail. Reports contain fixed codes/counts only.

Raw legacy Dests and nested Names/Dests name trees are resolved without action execution. Local GoTo destinations, including Next action chains, must resolve to source page identities outside **all** reflowed source pages unless each affected destination has an authorized FitR move. All USED named/legacy destination definitions and alias-chain values are privately fingerprinted in full, including explicit mode, coordinates, unknown definition keys and page-identity references. Saved output re-resolves those same definitions and compares their full normalized values before transport and after serialization; changing a target page, target coordinates/mode, key or used definition refuses even if the annotation Dest string is unchanged. Unused catalog definitions are not blanket-fingerprinted.

Annotation AA/PA, page AA and catalog AA/OpenAction roots are conservatively refused for reflow because this adapter does not prove their trigger/target semantics. Unknown non-action annotation data is still preserved in full. A provably absent named/legacy target may stay broken exactly as in the source: no target is guessed, created or repaired. The private exact missing key and used alias-chain values are rechecked against complete bounded legacy/Names catalogs before and after transport. Introducing any definition (even outside the reflow group), changing its name/alias, making it ambiguous or producing a malformed catalog fails validation. This preservation emits only fixed `source-broken-link-preserved` warnings with numeric page/annotation indices. Other unresolved arrays or unsupported action target semantics anywhere in the document block reflow because their targets cannot be proved unaffected. A destination inside reflowed pages remains a barrier unless covered by a valid FitR move, even if its label is on an edge. URI and known URI/GoTo Next actions are retained; unsupported action semantics are never silently dropped.

Only Link is transportable. Shared annotation objects across Annots, tagged or ambiguous structure ownership, rotation/crop/offset mappings, invalid rectangles/quads, target overflow, splits and nonconstant/multiple moves refuse. Unsupported annotations outside changed groups can remain byte/semantic intact; their identifiable internal targets are still gated. The caller must independently prove source-glyph associations, unchanged label text, one destination page and constant translation; this helper does not infer body text flow or trust a report's proposed moves.

Limits: source 25 MiB, output 64 MiB, 200 pages, 2000 annotations, depth 20, 200000 traversed fingerprint objects, 4 MiB processed stream bytes and 4 MiB processed strings per inventory. Fingerprinting is deliberately conservative about graph/storage changes. Native allocations are bounded by input and these counters, not an OS memory sandbox. Same-engine annotation checks are not independent visual/scientific verification. The caller owns worker timeout/cancellation and whole-document rendering/text QA.

Tests use synthetic PDFs and the installed MuPDF WASM. They cover direct/indirect existing dictionaries; repeated labels; URI, named/legacy destinations and Next GoTo; unknown nested fields and binary streams; two simultaneous original-index moves; fixed-edge preservation; inserted-page identity mapping; shared empty-array isolation; source immutability; hash/map/ownership/tag/geometry refusal; unresolved external-owner targets; and drop/alter-action/stream/URI validation negatives, cyclic unknown graphs and stream/depth budget refusal. No user PDF, model call or upload is involved.

Independent-review regressions additionally cover output-only named/legacy target-page, coordinate, mode, name-key and unknown-definition mutations, alias-chain changes, and hidden AA GoTo/other unproved action-owned roots.

Missing-target regressions cover unchanged direct/alias-chain absence, output-only definitions added in either Names or legacy Dests (inside and outside flow), changed missing names, malformed/duplicate catalogs and unchanged AA/unknown-target barriers. No raw missing key leaves the private model.

A catalog with no Names and/or Dests entries is a valid empty lookup: URI-only links and strict missing-name absence proofs remain supported. A PRESENT malformed Names or Dests root is still refused. Legacy-only Dests catalogs require no Names dictionary.

The private source-bound inspection model additionally exposes `internalDestinations` per annotation: `{id,kind,targetSourcePageIndex,operands}`. IDs are opaque per inspection and shared resolved raw destination objects have the same ID. Kinds are the fixed PDF destination modes accepted by the reader; operands are numbers or null, bounded to absolute value 100000. An out-of-bound operand suppresses its descriptor and retains the existing target barrier. The trusted embedded caller may supply optional `destinationMoves:[{id,sourcePageIndex,outputPageIndex,dx,dy}]` to transport and validate. The ID is bound to the immutable inspected model; it is not accepted from request JSON. Each affected destination must be a numeric, bounded FitR array with the exact original page and operands. Each ID occurs once, its source page is reflowed, its final physical output page is valid, and translation is finite and bounded. Other modes, missing moves, conflicting or duplicate IDs and unsupported destinations are refused. Shared arrays and aliases are mutated once in place, preserving their identity. Validation checks the exact authorized page and four translated coordinates, then normalizes only those values for the existing full semantic and named-definition fingerprints. No movement retains the original exact fingerprint behavior. The saved and reopened document is validated again. This is an adapter implementation check; `sourceBuildVerified` remains false and the caller remains responsible for independent RED/BLUE/review and visual checks.

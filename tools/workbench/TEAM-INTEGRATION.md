# Workbench alpha.63 소스 동기화

`tools/workbench`는 `Shinick-Han/falsify-workbench`의 0.2.0-alpha.63 소스 스냅샷입니다.

- 소스 커밋: `76337734899cb13e9bc8c43261cf2de70354cae9`
- 공개 웹: https://shinick-han.github.io/falsify-workbench/
- 설치 ZIP: https://github.com/Shinick-Han/falsify-workbench/releases/tag/v0.2.0-alpha.63
- 소스 파일 1,314개를 동기화합니다.
- 이 저장소의 `INTEGRATION-SOURCE.json`과 이 문서는 팀 통합 메타데이터로 유지합니다.

이번 버전은 경찰과 도둑(BLUE 블라인드 결함 검증기 vs RED 결함 주입 테스트기) 상보적 진화 구조(v2)를 구현하고 BLUE 시각 단계 인덱싱(`latex-source.browser.cjs`) 상호작용을 바로잡았습니다: 오라클 기준 `D1~D4-1`·`S1` 결함 택소노미 및 `L1~L4` 난이도·맹검 누출 원천 차단 게이트, BLUE Layer 0 PDF 포렌식 센서(`/URI` 하이퍼링크↔서지 대조, 중복 참고문헌, `AcroForm` 위젯 누락, 다중비교 보정 `p`값 예외 처리)와 `P0`/`P2`(DataCite 포함) 증거 팩, 1단계 의심 원장 누락 자동 복원(Zero-Drop 2단계 검증), `검수(H1)` 비정답 지적 4분류 정밀 감사, `결과 기록(A1)` 상보적 진화 스코어보드 및 팀 `score.py` 호환 12열 CSV·Red JSON 내보내기를 포함하며 운영 코드 CCN 15 상한(`sourceBuildVerified: false`)을 만족합니다.

이 브랜치의 Workbench 경로만 갱신하며 공식 프로젝트의 다른 코드와 연구 자료는 유지합니다. 라이선스와 설치·실행 절차는 포함된 upstream 문서를 따릅니다.

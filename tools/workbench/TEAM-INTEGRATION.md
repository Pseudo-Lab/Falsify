# Workbench alpha.61 소스 동기화

`tools/workbench`는 `Shinick-Han/falsify-workbench`의 0.2.0-alpha.61 소스 스냅샷입니다.

- 소스 커밋: `b94432874ace1edf4348ee0aa5538d359facc3c5`
- 공개 웹: https://shinick-han.github.io/falsify-workbench/
- 설치 ZIP: https://github.com/Shinick-Han/falsify-workbench/releases/tag/v0.2.0-alpha.61
- 소스 파일 1,300개를 동기화합니다.
- 이 저장소의 `INTEGRATION-SOURCE.json`과 이 문서는 팀 통합 메타데이터로 유지합니다.

이번 버전은 BLUE 결정론적 통계·산술 사전 감사(`audit_statistics`), 생략 표·그림 재열람(`omittedIds`) 및 다중 실행기 시각 증거·자동 확대 재독해, 내장 RED 반복 구절 `occurrence`·다중 양식 후보·통합 RED MCP·포렌식 은닉 자체검사, 전수 참고문헌(Crossref/Europe PMC)·`ClinicalTrials.gov` v2 임상등록 대조(`evidence_blue_v036`)를 포함하며 운영 코드 CCN 15 상한(`sourceBuildVerified: false`)을 만족합니다.

이 브랜치의 Workbench 경로만 갱신하며 공식 프로젝트의 다른 코드와 연구 자료는 유지합니다. 라이선스와 설치·실행 절차는 포함된 upstream 문서를 따릅니다.

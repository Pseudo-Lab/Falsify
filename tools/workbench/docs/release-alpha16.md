# 0.2.0-alpha.16

The public Workbench and companion source share this version. Download the matching source ZIP for new local execution features; updating the web page does not replace a running companion.

This release adds optional PDF visual input for built-in Codex, page and region selection, condition-matched Harness comparison, bounded DOCX/HTML/ODT export and cross-tab pending-job admission. Confluence remains the only permanent remote archive. Existing records and independent RED, BLUE and human-review flows remain supported.

Visual input is tested with real PDF rendering and a fake CLI provider, not a scientific performance experiment. ODT ZIP/XML preservation and Word text opening passed; PDF rendering did not complete, so visual layout is unverified. Editing still has table, figure and multi-column limits. The cold-shower eight-edit case remains 15 to 18 pages with zero compacted groups. Failure-attempt denominators, verified model costs and server-restart job persistence are not implemented.

The pinned native runtime bytes are unchanged. SourceBuildVerified remains false. Private papers, harness configurations, answer keys and experiment records are excluded from the release.

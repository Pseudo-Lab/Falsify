# PDF 문단 재배치 수정 · alpha.30

두 단 논문에서 좌우 본문이 하나의 문단으로 추출되면 편집기가 다른 단까지 옮기거나 페이지 경계 오류로 생성을 중단했다. 선택한 단을 분리해 편집하고 원래 객체를 복원하도록 수정했다. 문단 사이 여백을 먼저 사용하고, 새로 겹치는 그림·도형은 충돌로 판단한다. 이미 원본에 있던 마스크 겹침은 그대로 유지한다.

편집 후 위첨자 인용번호는 원문의 문맥·서체·색상으로 대응 위치를 확인해 이동한다. 닫는 괄호에 붙은 인용도 포함한다. 한 단짜리 문서의 기존 페이지 압축과 링크 이동 경로는 유지했다. 오류 문구의 페이지 번호는 PDF 화면과 같은 1부터 표시한다.

## 확인한 범위

- 비공개 36쪽 훈련 PDF에 교체 세 건과 삭제 한 건을 함께 적용해 36쪽을 유지했다.
- 별도 PDF 렌더러로 편집하지 않은 33쪽의 픽셀 동일성을 확인했다.
- 공백과 줄 끝 하이픈을 정규화한 추출에서 교체 문구가 각각 한 번 나타나고 삭제 구절이 사라짐을 확인했다.
- 편집한 본문의 인용번호 이동을 별도로 확인했다. 이 검사는 논문 주장의 과학적 검증과 구분된다.
- 단 분리·복원·실패 시 객체 수명, 여백 전파·그림 충돌, 한 단 문서 압축, 위첨자 대응의 회귀 검사를 추가했다.

## 남은 출력 품질

해당 실문서에서 편집 문단의 일부 단어 내부 간격이 벌어지고, PDF 텍스트 스트림 순서와 화면 순서가 다르다. 같은 엔진의 예상문·위치 검사는 실패 상태를 유지한다. 인용번호의 링크 주석 영역은 별도 검증이 필요하다. 미리보기와 다운로드는 제공하며, 이 출력을 레이아웃 검증 통과로 표시하지 않는다.

새로운 글꼴·PDFium/WASM 빌드를 포함하지 않는다. 논문과 생성본은 공개 소스·릴리스에서 제외한다.
## alpha.31 · After 존재 검사

출력 PDF의 추출기가 단어 내부에 생성한 공백 때문에 실제로 존재하는 After도 `after_missing`으로 표시되는 사례를 수정했다. 기존 이어지는 페이지 검사에서 사용하던 generated-whitespace 규칙을 문구 존재 검사에도 적용한다. 추출기가 생성했다고 표시한 공백만 선택적으로 건너뛰고, 사용자가 입력한 공백·모든 문자·문자 순서는 유지한다.

같은 실문서의 2·5·10쪽에서 세 After가 모두 확인됐다. 화면에는 확인한 문구 개수를 표시하고, 전체 내용·읽기 순서 대조 실패는 별도로 유지한다. 문구가 있다는 사실로 페이지 전체 보존이나 자간·배치 검사를 통과시키지 않는다. 실제 문자가 없거나 바뀐 경우의 실패도 유지한다.

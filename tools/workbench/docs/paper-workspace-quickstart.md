# 논문 작업대 빠른 사용

화면 문구가 이 문서와 다르면 화면을 따릅니다. 배포 버전 번호는 루트 릴리스 전에 적지 않습니다. 같은 내용의 긴 설명은 [사용 안내](../app/dist/guide.html)에 있습니다.

1. **원본에서 편집을 고릅니다.** `RED 논문 파일`로 PDF를 열면 `원본 쪽 보기 · 직접 편집`에서 글자를 고르고 `적용`합니다. 이 직접 편집은 모델을 호출하지 않습니다. PC 없이 외부 모델을 쓰려면 `원문과 과제 프롬프트 복사`로 과제를 옮기고, 응답을 `붙여넣은 응답`에 넣은 뒤 `변경 찾기`를 누릅니다. 한 곳이면 `이 변경을 가져오기`, 여러 곳이면 위치를 하나 고르고 `고른 위치로 확정`한 다음 `선택한 변경 가져오기`입니다. 앱은 그 모델을 호출하거나 응답을 자동 적용하지 않습니다. 로컬 AI는 `AI 검토 · 선택 사항`을 연 뒤의 선택입니다.
2. **생성본을 미리보고 받습니다.** `수정본 미리보기 만들기` 뒤의 미리보기와 `현재 생성본 다운로드`는 그 파일 바이트입니다. 원본은 `원본 다운로드`로 따로 받으며 바뀌지 않습니다. 이후 편집이 바뀌면 `마지막 생성본 · 현재 편집과 다름`입니다. 경고는 레이아웃 인증이 아닙니다. 좌표 편집과 긴 문장 재배치는 회전이 없고 잘리지 않은 1단 본문에 한정됩니다.
3. **RED 후보를 저장합니다.** AI 검토 또는 수동 응답의 후보에서 Before와 After를 확인하고 원하는 변경만 선택합니다. 실험용 사본 동의 후 `수정본 다운로드`를 누릅니다. `편집 엔진과 검사 범위`에서 지원 범위를 확인하고, 변경 근거는 `변경 계획 JSON 저장`으로 따로 보관합니다. BLUE에는 수정 파일만 넣습니다.
4. **BLUE와 사람 검수를 따로 합니다.** BLUE는 `BLUE 검토 파일`에 시험 파일을 직접 올립니다. `이 생성본만 BLUE로`는 생성 PDF만 넘깁니다. 사람 판정은 `검수 기록 추가` 또는 `사람 검수 추가`입니다. 원격 보관은 명시적 팀 공유의 Confluence뿐입니다. `팀에 공개`는 그 자체로 업로드가 아니며, 화면의 공개 동의 체크와 `공개하고 저장`을 따릅니다. 원본 PDF 바이트와 비공개 초안은 올리지 않습니다.

`이 브라우저에 12시간 초안 보관`을 켜고 `초안 저장`할 때만 편집 기록이 남습니다. 원본 PDF는 별도 체크 `원본 PDF도 이 브라우저에 12시간 보관`을 켠 경우에만 이 브라우저 Blob에 남고, 서버로 올라가지 않습니다.

Windows PowerShell 5.1과 PowerShell 7, 그리고 macOS의 로컬 승인·다시 연결은 안내의 연결 절을 봅니다. 승인 뒤 같은 탭은 최대 12시간 동안 연결 상태만 다시 확인하고, `연결 해제`가 그 자격을 취소합니다. 생성 경고와 사람 메모는 과학적 정확도를 보증하지 않습니다.

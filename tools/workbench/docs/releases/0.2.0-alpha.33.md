# Workbench 0.2.0-alpha.33

PDF 편집기 감사에서 확인한 결함과 통합 회귀를 수정한 버전입니다.

- 긴 문장 교체에서 원본 객체와 글꼴을 유지하고 뒤 문단을 배치합니다.
- 마지막 줄 전체 삭제와 저장 후 재편집에서도 가림 도형의 그리기 순서를 유지합니다.
- 표와 본문 동시 편집, 구조가 명확한 유선 표 재조판, 링크 목적지와 회전·CropBox 좌표 검사를 수정했습니다.
- Tab 이동 후 자동 미리보기와 입력 파일 교체 시 상태 초기화를 수정했습니다.
- 앱·companion·정적 자산 캐시 버전을 함께 갱신했습니다.

검증: Node 검사 569개 중 562개 통과, 7개 건너뜀, 실패 0건. 브라우저 전용 자동 검사는 CI에서 실행합니다. Aside 실제 화면에서 자동 미리보기, undo/redo, 다운로드와 BLUE 전달 파일의 해시 일치를 확인했습니다. 실제 36쪽 논문의 네 군데 편집은 36쪽을 유지했고 나머지 32쪽의 텍스트와 렌더링이 동일했습니다.

[상세 검증과 지원 범위](../pdf-editor-repair-20261030.html)에 표·글꼴·주석 처리 범위를 기록했습니다. 네이티브 엔진은 증분 빌드이며, 런타임과 패치 해시를 검증했습니다.

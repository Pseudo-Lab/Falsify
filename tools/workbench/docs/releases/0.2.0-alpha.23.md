# 0.2.0-alpha.23 — paper layout

PDF recomposition now uses source paragraph sizes and measured column flow, groups complete figure captions, and fits caption/artwork groups without shrinking text. Short body fragments can stay with the following figure rather than occupy a nearly empty page. Title-page notes remain with the text.

The browser checks each candidate and can make one page-bound repair when floats lose content or introduce detected layout defects. Source-corroborated line-wrap cleanup is recorded as layout normalization; user After stays literal. Header/footer fields use selected-font measurements and a real gap.

Two papers were tested with baseline, previous edits, long replacements and 600-word caption stress cases. All eight generated with matching ordered logical text or the documented character representations. Actual browser runs and pinned-Typst tests supplement the application regression suite. Private papers and outputs are excluded from the source release.

The overall layout score remains unavailable. Artwork scaling can make plot labels smaller, and exact source typeface or arbitrary complex-layout equivalence is not claimed.

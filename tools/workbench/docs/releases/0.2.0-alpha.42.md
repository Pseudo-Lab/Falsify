# 0.2.0-alpha.42

AI 배치 도구의 잘못된 명령을 피드백으로 되돌려 기존 단계 예산 안에서 정정하도록 했습니다. 취소된 요청은 종료하고, 명확한 접수 전 거절은 다음 사용자 실행이 가능하도록 정리합니다.

같은 실행의 최신 저장을 우선하고, 계속 실행할 때 영수증을 보존합니다. 새 실행이 실패해도 이전 PDF와 새 요청 정보를 함께 보관하며, 작업 ZIP 복원 후 접수 여부가 불명확한 요청을 조회로 복구합니다.

긴 원문, 기하 정보와 자산 목록을 응답 크기에 맞춰 나눠 읽습니다. 원본 조회의 명시적 위치 인자와 기존 offset을 지원하며, 잘못된 구조 메타데이터는 가져오는 단계에서 확인합니다.

기능 검증은 앱 Node 964개 통과·7개 건너뜀·실패0개, 서버27개·패키징11개와 독립 재현8개 통과입니다. 합성 자료와 응답 대역을 사용했으며 추가 RED/BLUE 모델 호출은 없습니다. [수정 내용과 확인 범위](../layout-pattern-repairs-20261101.md)를 참조하세요.

# 0.2.0-alpha.65

`0.2.0-alpha.64`(BLUE·RED·아레나 3개 축 1순위 6개 고도화 통합본)의 로컬 companion 실기동 HTTP 검증에서 발견된 `/api/paper/evidence/query` `operation: "supplement_audit"` 페이지 텍스트 추출 결함을 즉시 수정해 GitHub Pages와 로컬 설치본을 일치시킨 후속 프리릴리스입니다.

- **로컬 companion HTTP `supplement_audit` 페이지 추출 수정 (`paper_evidence_http.py`, `test_paper_supplement_audit.py`)**: `EvidenceStore.list_items`에 미지원 `kind='page'`를 호출하던 경로를 `_require_bound_pdf` + `_open_pdf` 페이지 텍스트 추출로 바로잡고, 단위·통합 회귀 테스트를 추가했습니다.
- **`0.2.0-alpha.64`의 3개 축 1순위 6개 고도화 전체 포함**:
  1. **BLUE 다중 파일 번들 교차 검증**: 본문 PDF와 보충자료(`Supplementary PDF/DOCX/TXT`, 표 `CSV/TSV`, 코드·로그) 교차 감사(`D4-1` 고아 보충 인용, `D1` 표본수·지표 불일치) 및 `supp-*` 구간 결합
  2. **BLUE Layer 0 심층 통계·임상 포렌식**: 유계 척도 `SPRITE`, 2×2 분할표(`a/N1 vs c/N2`) 정확 Fisher 양측 `p`·`χ²`·비보정 `OR/RR`(`aOR/aRR` 오탐 제외), Kaplan-Meier `No. at risk` 단조 감소 위반 정적/오프라인 감지
  3. **BLUE `P2` 철회 문헌 감지 및 사전등록·기탁번호 검증**: Crossref·Europe PMC 철회/우려 표명 인용 감지와 `OSF`·`PROSPERO`·`GEO`·`PDB` 구문(`P0`) 및 공개 레코드(`P2`) 검증
  4. **RED 원본 사전 결함 스캔(Baseline Guard) 및 무손실 PDF `/URI` 하이퍼링크 변조기**: 주입 전 기존 오류 충돌 경고 및 페이지 픽셀 무변화 `/URI` 링크 은밀 변조(`W5 D2-1·D2-3`)
  5. **아레나 다자 평가자 일치도(`Krippendorff's α`) 및 `확인필요` 선택적 예측(`Risk-Coverage / AURC`)**: 명목·서열 α 및 보류율·선택적 정확도·보류 순이득(`Abstention Gain`)·`AURC` 산출

`sourceBuildVerified`는 `false`로 유지됩니다. 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.65`)으로 업데이트하세요.

# Workbench 0.2.0-alpha.34

원본 LaTeX 프로젝트 편집을 추가한 버전입니다.

- `.tex`와 소스 ZIP을 읽고 브라우저의 고정 BusyTeX/pdflatex로 PDF를 생성합니다.
- 본문·수식·첨자와 기본 각주·인용 표기를 소스 구조에 맞춰 편집합니다.
- 외부 RED 응답 가져오기, 변경 표시, undo/redo, 작업 JSON 저장·복구와 동일 PDF의 BLUE 전달을 연결했습니다.
- 파일 전환 중 늦게 끝난 복구·미리보기 작업이 새 문서를 덮거나 닫는 오류를 수정했습니다.
- 기존 PDF 편집을 유지하며, PDF에서 편집용 LaTeX를 만드는 실험 기능은 고급 옵션에 두었습니다.

최종 로컬 전체 검사: Node 요약 692개 중 685 통과, 7 건너뜀, 실패 0. 추가 집중 검사 27개 통과. Windows Aside에서 실제 WASM 컴파일·다운로드/BLUE 파일 일치·작업 복구를 확인했습니다. GitHub CI에서는 Linux 브라우저와 macOS/Windows 연결 검사를 별도로 실행합니다.

PDF 재구성은 원래 TeX를 복원하는 기능이 아닙니다. 복잡한 다단 문서·수식·원본 배치 품질 개선이 남아 있으며 기존 PDF 편집의 대체 기본값으로 사용하지 않습니다. 처음 소스 컴파일에는 약 128MB의 고정 실행 자산을 내려받습니다.

# 0.2.0-alpha.64

경찰(`BLUE` 블라인드 결함 검증기)과 도둑(`RED` 결함 주입 스트레스 테스트기), 그리고 학술 평가 아레나(`A1`)의 **3개 축 1순위 6개 고도화 항목**을 전면 통합한 프리릴리스입니다.

- **BLUE 다중 파일 번들 교차 검증 (`blue-supplement-bundle.js`, `paper_supplement_audit.py`, `document-blue.js`)**: 주 논문 PDF와 보충자료(`Supplementary PDF/DOCX/TXT`, 표 `CSV/TSV`, 코드·로그 `.py/.r/.json/.log` 최대 8개)를 동시에 투입해 ① 첨부 자료 어디에도 없는 고아 보충 인용(`Table S4`, `Fig. S3` 등 `D4-1`), ② 본문 표본수(`N = ...`)와 보충 표/로그 행 수 불일치(`D1`), ③ 본문 인용 보충 수치와 실제 보충자료/로그 지표 불일치(`D1`)를 결정론적으로 감사하고 로컬·외부 BLUE 검토 구간(`supp-*`)에 무결성 있게 결합합니다.
- **BLUE Layer 0 심층 통계·임상 포렌식 (`paper_stat_math.py`, `paper_stat_audit.py`, `blue-defect-sensor-core.js`)**: 순수 표준 수식(외부 패키지 무의존)으로 ① 유계 척도 평균·표준편차·표본수 분포 가능성(`SPRITE` · Bhatia-Davis 및 정수 격자 극값 한계), ② 2×2 분할표(`a/N1 vs c/N2`) 정확 Fisher 양측 `p`·Pearson/Yates `χ²` 및 비보정 `OR/RR` 정합성(`aOR`/`aRR` 다변량 보정 지표는 오탐 제외), ③ Kaplan-Meier 생존표 `Number at risk` 시계열 단조 감소 위반을 서버와 PC 미연결 브라우저(`P0`) 양쪽에서 즉시 포착합니다.
- **BLUE `P2` 철회 문헌 감지 및 사전등록·기탁번호 검증 (`paper_external_grounding.py`, `paper_registry_identifiers.py`, `paper_blue_sensor.py`)**: Crossref(`update-to`·`relation`) 및 Europe PMC(`Retracted Publication`·`Expression of Concern`) 메타데이터로 철회·우려 표명 논문을 정상 인용한 서지(`D2`)를 식별하고, `OSF`(`osf.io/...`), `PROSPERO`(`CRD420...`), `GEO`(`GSE...`), `PDB` 식별자의 오프라인(`P0`) 형식 검사와 고정 호스트 TLS(`P2`) 공개 레코드 대조를 수행합니다(API 미조회가 곧바로 조작 증명은 아님을 명시).
- **RED 원본 사전 결함 스캔(Baseline Guard) 및 무손실 PDF `/URI` 하이퍼링크 변조기 (`red-baseline-uri.js`, `paper_uri_mutator.py`, `paper_red_mcp.py`)**: 결함 주입 전 원본 논문의 기존 Layer 0 수치·인용 결함을 사전 스캔해 기존 오류 위치에 중복 주입하는 채점 오염을 방지하며, 페이지 렌더링 픽셀을 100% 보존한 채 PDF 내부 `/URI` 링크 대상만 은밀하게 치환하는 `D2-1`·`D2-3` 스트레스 테스트 도구를 웹 작업대와 `paper_red_mcp.py`(`scan_source_baseline`, `list_pdf_links`, `uri-link`)에 추가했습니다.
- **아레나 다자 평가자 일치도(`Krippendorff's α`) 및 `확인필요` 선택적 예측(`Risk-Coverage / AURC`) (`coevolution-arena.js`, `tools/evaluation/agreement_selective.py`)**: 결측치를 허용하는 우연 일치 행렬 기반 명목·서열 `Krippendorff's α`(`H1` 검수자 간 및 반복 BLUE 실행 간 합의도)와 `확인필요` 보류율(`Abstention Rate`)·확정 지적 선택적 정확도(`Selective Accuracy`)·보류 순이득(`Abstention Gain`)·위험-커버리지 곡선 아래 면적(`AURC`)을 산출해 보류 메커니즘의 실효성을 정량 증명합니다.

`sourceBuildVerified`는 `false`로 유지됩니다. 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.64`)으로 업데이트하세요.

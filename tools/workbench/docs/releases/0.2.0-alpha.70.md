# 0.2.0-alpha.70

이번 프리릴리스는 외부·로컬 AI 에이전트가 환자 흐름(CONSORT) 산술 감사·스핀 단서 분리, 코드 보충자료 정적 AST 대조, 다표면(`L3`/`L4`) 교차 변조 계획·보충자료 변조 내보내기, PDF 합자·줄바꿈 인용 정규화 및 수리 팩 산출, 다중 논문 워크스페이스 우선순위 선별, 다세대(`<= 3`) 무인 공진화 캠페인과 18케이스 회귀 벤치마크까지 단일 헤드리스 루프로 수행하도록 확장한 **Agent-First 4차 4개 축 1순위** 구현입니다. 배포·설치 동작은 이전 버전과 같고 `sourceBuildVerified`는 `false`로 유지됩니다.

- **BLUE 환자 흐름(CONSORT) 산술 감사 & 의미론적 스핀 단서 분리 (`app/local/paper_flow_and_spin_triage.py`, `paper_blue_sensor.py`, `paper_mcp.py`)**: `Screened − Excluded = Randomized`, 군 배정 합계, 추적 탈락·분석 대상(`Randomized − Discontinued = Analyzed`), 기저 특성 표 하위집단 분모(`k/n`, 결측 각주 면제)와 상호배타 범주 합계를 결정론적 결함(`signals`)으로 산출하고, 비무작위·유의성 미달 연구의 단정적 인과 표현(`D3`) 및 수치 역전 주장(`S1`)은 확정 결함과 분리된 `triageHints`(`advisoryOnly: true`)로만 제공합니다(`audit_flow_and_spin`, `falsify blue scan --flow-triage`).
- **코드 보충자료 정적 AST/정규식 감사 & 포터블 `BLUE Evidence v0.3.9` (`app/local/paper_code_audit.py`, `app/examples/evidence_blue_v039`)**: 스크립트를 절대 실행하지 않고 `.py`/`.R`/`.Rmd`/`.sql`을 정적 분석해 단측·양측 검정 불일치(`code_tailness_mismatch`), 분할 전 전체 데이터 전처리 누수(`code_preprocessing_leakage`, `Pipeline` 내부는 면제), 유의수준·절단값 불일치(`code_hardcoded_threshold_mismatch`), 미고지 행 필터링(`code_undisclosed_row_filter`)을 탐지합니다(`audit_code_supplements`, `falsify blue scan --audit-code`). 동결된 `v0.3.1`–`v0.3.8`을 보존한 채 신규 `evidence_blue_v039`에서 코드·환자흐름 Triage 다이제스트와 타이포그래피 인용 폴딩·Zero-Drop 복원·1회 수리 게이트를 결합했습니다.
- **RED 다표면(`L3`/`L4`) 연쇄 변조 플래너 & 포터블 `RED Injector v0.2` (`app/local/paper_red_planner.py`, `app/examples/adversarial_red_v02`)**: `plan_coordinated_mutation`(`falsify red plan`, RED MCP 도구)이 전파 그래프 위에서 본문·표·보충자료 동시 변조와 단일 표면 누락 대안을 시뮬레이션해 목표 난이도 이상의 실행 가능 계획을 합성합니다. `falsify red apply --out-supplement-dir DIR` 및 신규 포터블 `adversarial_red_v02`는 변조된 PDF+보충자료 맹검 번들과 봉인 정답 원장(`falsify.red-gold-ledger.v1`)을 분리 산출합니다(`adversarial_red_v01` 불변 보존).
- **PDF 타이포그래피 인용 폴딩 & 자가 수리 팩 (`app/local/blue_report_validate.py`, `falsify_cli.py`)**: 합자(`ﬁ`/`ﬂ`/`ﬀ`/`ﬃ`/`ﬄ`), 줄바꿈 하이픈, 유니코드 마이너스(`−`), 스마트 따옴표, `µ`/`μ` 차이를 `status: "normalized"`로 수용해 거짓 환각 판정을 제거하고, 진짜 미일치 인용에 대해 정답 키가 제거된 `falsify.quote-repair-pack.v1`(`--emit-repair-pack PATH`)을 산출합니다.
- **다중 문서 워크스페이스 보충자료 자동 페어링 & 배치 우선순위 선별 (`app/local/paper_mcp_workspace.py`, `falsify_cli.py`)**: `--workspace DIR` 및 `falsify blue scan-workspace`가 논문별 동반 보충자료(`<stem>_supp*`, `supplements/<stem>/*`, 정답 파일 마스킹 유지)를 자동 결합하고 `triage_workspace`(`falsify.workspace-triage.v1`)로 코퍼스 전체의 Layer 0 위험도 순위를 산출합니다. `falsify mcp-config --role red|both --supplement PATH`도 함께 지원합니다.
- **무인 다세대 공진화 캠페인 & 18케이스 벤치마크 v2 (`tools/evaluation/arena_campaign.py`, `tools/evaluation/benchmark_suite.py`)**: `falsify arena evolve`가 코퍼스·세대 상한(`generations <= 3`)과 Holdout 순수 오탐 무증가 가드 아래 RED·BLUE 라운드와 패치 승격·롤백 계보를 자동 기록하며, `falsify arena benchmark`(`falsify.benchmark-report.v2`)를 11종 Gold(원자료 CSV·`.py` 전처리 누수·CONSORT 흐름 불일치 포함) + 7종 Benign-Trap Holdout(합자 PDF·`Pipeline` 교차검증 스케일링·결측 각주 표 등) 총 18케이스로 확장했습니다.

검증은 생산 코드 CCN `max 15`(`247`개 파일 `12,551`개 함수, `>15: 0`), 앱 Node·Cloud API(`57`개)·브라우저 합성 회귀 스위트, 포터블 러너(`v033`–`v039` `47`개 및 `adversarial_red_v01`–`v02` `11`개 총 `58`개), 평가·벤치마크 스위트 `79`개, 앱 Python 전체 스위트 `1,273`개(`skipped=7`, `failures=0`), 패키징 ZIP 수용 검사로 확인했습니다. 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.70`)으로 업데이트하세요.

# Workbench 0.2.0-alpha.38

The layout agent can inspect the original PDF, adjust source layout through 23 tools, retain candidate PDFs and checkpoints, and resume saved work. Results distinguish content differences, detected layout issues and the pages actually observed.

The workbench adds explicit 12-hour draft recovery, cached comparisons, corresponding-page matching, finding-region markers and asynchronous step receipts. BLUE receives the selected PDF only. Table extensions cover verified multi-run cells and single-column source longtables with repeating headers.

Detected merged PDF cells, reconstructed/two-column breakable tables and whole-paper reconstruction fidelity remain follow-up work. This release uses the existing CLI subscription connection.

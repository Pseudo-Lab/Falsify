# 0.2.0-alpha.43

BLUE에서 논문 표·그림을 원본 위치와 함께 읽을 수 있습니다. 스캔 PDF는 쪽별 OCR로 텍스트와 표를 준비하고, 그래프는 영역을 드래그해 표로 받습니다. 자동으로 BLUE 모델을 실행하지 않습니다.

- 표 셀·병합 구조·그림 영역과 읽기 전용 논문 MCP를 추가했습니다.
- 한국어 띄어쓰기를 보완하고 원 판독문을 함께 보존합니다. 숫자·문자는 바꾸지 않습니다.
- Windows 격리 프로세스의 한국어 출력 인코딩을 수정했습니다.
- 선형·로그·이중 축 곡선을 눈금과 원본 픽셀로 측정합니다. 축 연결이 모호하면 양쪽 후보를 남깁니다. 다른 그래프에는 DePlot을 사용합니다.
- 결과는 파일 해시·쪽·영역·입력 이미지·엔진 출처에 연결되며 JSON·CSV로 받을 수 있습니다.
- 구형 companion에는 업데이트 안내를 표시하고 선택형 OCR·그래프 설치 안내를 연결했습니다.

별도 분석 환경에 공개 모델을 설치합니다. 모델은 요청 중에만 실행하고 완료·취소 후 종료합니다. 모델 가중치와 사용자 논문·기록은 릴리스에 포함하지 않습니다.

[사용법·설치·확인 범위](../paper-ocr-chart.md). 실제 브라우저에서 한국어 OCR, 로그·이중 로그 축 읽기, JSON 다운로드를 확인했습니다. 공개 웹 배포와 설치본 교체 영수증은 WorkBite T-0152에 기록합니다.

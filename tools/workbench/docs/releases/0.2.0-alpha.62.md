# 0.2.0-alpha.62

Falsify Confluence 연구 기록의 역할 정의와 실험 교훈을 반영해 **경찰(`BLUE` · 블라인드 결함 검증기) ↔ 도둑(`RED` · 결함 주입 스트레스 테스트기) 상보적 진화 v2** 아키텍처를 병렬 통합한 프리릴리스입니다.

- **RED 오라클 기반 결함 분류(`D1`~`D4-1`·`S1`)·은닉 난이도(`L1`~`L4`) 및 맹검 누출 원천 차단 (`adversarial-taxonomy.js`, `document-red-core.js`, `document-red.js`, `red_service.py`, `paper_stealth_audit.py`)**: 결함 계열(`D1` 수치·표·그림 불일치, `D2` 인용·서지·링크 왜곡, `D3` 근거보다 센 결론·스핀, `D4-1` 결과 지위 오표기, `S1` 도메인 기전·극성 역전)과 은닉 난이도(`L1` 단일 국소 ~ `L4` 다중 양식 연쇄)를 독립 축으로 분리하고, `numeric-drift`·`citation-distortion`·`outcome-status-mislabeling`·`semantic-inversion` 공격 유형을 추가했습니다. 결함 주입 힌트 문자열이나 PDF 주석·양식 흔적이 섞인 사본은 BLUE 전달·내보내기 전에 차단합니다.
- **BLUE Layer 0 결정론적 감식(`P0`·`P2`) 및 다중 검정 보정 `p`-값 오탐 방지 (`paper_blue_sensor.py`, `paper_evidence_http.py`, `paper_stat_audit.py`, `blue-defect-sensor-core.js`, `blue-defect-sensor-ui.js`)**: 모델을 부르기 전에 브라우저(`P0`)에서 수치·통계 정합성 및 참고문헌↔본문 인용 누락을 즉시 스캔하고, companion 연결 PDF에서는 하이퍼링크(`/URI` 대 인쇄 DOI/URL 불일치)·양식 필드(`AcroForm`) 포렌식과 명시적 외부 오라클(`P2`, Crossref·Europe PMC·임상등록부) 대조를 결합합니다. Bonferroni·FDR·BH·Holm 등 다중 검정 보정 `p`-값 표기는 단변량 재계산 `p` 불일치로 오탐하지 않고 `adjusted_p_noted`로 구분합니다.
- **외부 BLUE Zero-Drop 2단계 검증 프로토콜 (`prompt-instructions.js`, `external-exchange.js`, `external-proposals.js`, `external-blue-ui.js`)**: 기본 BLUE 프롬프트와 파서에 `1단계 의심 목록` → `2단계 최종 결함 표` 구조 및 `맞음` / `확인필요` / `검증됨_이상없음` 분리 규칙을 도입했습니다. `검증됨_이상없음`은 결함 건수에서 제외해 감사 추적에만 남기고, 1단계 의심 목록에 있었으나 근거 없이 최종 표에서 누락된 항목은 `확인필요 · Zero-Drop 누락 복원`으로 자동 복원합니다.
- **검수(`H1`) 4분류 정밀 감사 및 상보적 진화 아레나(`A1`)·팀 평가 스키마 호환 (`review-workbench.js`, `experiment-ledger.js`, `review-bundle.mjs`, `coevolution-arena.js`)**: BLUE 비정답 지적을 `실제 원문 결함`·`스핀/과장 경계`·`정답지 오류 (Gold v2 후보)`·`순수 오탐`으로 세분화해 검증기의 실제 원문 결함 포착 능력과 순수 오탐을 분리합니다. `결과 기록(A1)` 아레나에서 `P0`·`P2`·`Holdout` 조건별 엄격·포괄 이중 점수판, 동일 모델 계열 자가 대결 편향 경고, 동일 입력 반복 실행 판정 뒤집힘(`Flip`) 추적, 팀 `tools/evaluation/score.py` 호환 12열 CSV·Red 정답지 JSON 내보내기, 정답 미노출 `C1` Harness 개선 지침 초안을 제공합니다.

통합 검증에서 생산 코드 복잡도(`inventory.mjs --check`, 230개 파일 11,198개 함수 `max CCN = 15`, `>15: 0`, 파싱 오류 0), 앱 등록 Node 스위트 210개 전체 통과, 패키징 검사 13개 통과, 평가 스위트(`tools/evaluation`) 24개 통과, Python 계약 스위트 1,057개 통과(7개 환경 건너뜀, 실패 0개)를 확인했습니다(`sourceBuildVerified`는 `false` 유지). 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.62`)으로 업데이트하세요.

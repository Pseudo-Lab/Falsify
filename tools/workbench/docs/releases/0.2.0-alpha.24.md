# 0.2.0-alpha.24 — repeated footer pagination

Fixes a reproduced 36-to-83-page recomposition of the second Falsify training paper. Repeated publisher and notice lines on a shallow background band were treated as full-width body paragraphs, creating mostly empty pages.

The flow planner now recognizes a bounded repeated footer group from source geometry, repeated distinct text, matching bands and central body evidence. It preserves the text in running furniture. Nearby images, other artwork, lower scientific notes and edited footer content retain their existing protections. The fix does not delete output pages, rewrite After text or add an export blocker.

The original eight-case verification covered the first training paper and the cold-shower paper. This release adds the distinct second-paper input and the exact reported edit. Overall visual quality and exact source typeface equivalence remain separate from detected layout checks.

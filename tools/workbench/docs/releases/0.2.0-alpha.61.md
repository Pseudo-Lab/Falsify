# 0.2.0-alpha.61

BLUE 결정론적 산술·통계 사전 감사, 생략된 표·그림 선택형 재열람 및 다중 실행기 시각 증거·자동 확대 재독해, 내장 RED 반복 표현 오프셋·다중 양식 후보·통합 RED MCP·포렌식 은닉 자체검사, 그리고 전수 참고문헌(Crossref/Europe PMC)·`ClinicalTrials.gov` v2 임상등록 대조(`evidence_blue_v036`)를 병렬 통합한 프리릴리스입니다.

- **BLUE 결정론적 산술·통계 사전 감사 (`paper_stat_math.py`, `paper_stat_audit.py`, MCP `audit_statistics`)**: 외부 과학 라이브러리 없이 순수 Python 표준 수식으로 `z`·`t(df)`·`χ²(df)`·`F(df1, df2)` 대비 `p`-값 정합성(반올림 경계 및 단측·양측 확인), `n/N (%)` 백분율, GRIM 정수 표본 입도, 신뢰구간(`CI`) 포함·로그 대칭성(`OR`/`RR`/`HR`), 본문↔표↔그림 3자 수치 불일치를 사전 계산해 BLUE 문맥과 읽기 전용 MCP `audit_statistics` 도구로 제공합니다.
- **BLUE 생략 표·그림 재열람 및 다중 실행기 시각 증거·자동 확대 (`blue_structured_reread.py`, `blue_visual.py`, `cli_backend.py`)**: 긴 논문 다중 묶음 검토의 `selecting` 단계에서 초기 24,000자 예산 밖으로 밀린 표·그림(`omittedIds`)을 `evitem:<itemId>` 앵커로 선택해 `final` 단계에서 원문 구조 그대로 재확인합니다. 검증된 PNG 상한을 6장으로 넓히고 Codex뿐 아니라 구독 인증 Claude Code(`--input-format stream-json`, `--tools ""` 유지)와 명시 동의한 `stdio`/`wrapper` 하니스에서도 시각 증거를 전달하며, 그림 언급 지적 시 자동 고해상도 영역 크롭 2단계 재독해(`autoVisualReread`)를 지원합니다.
- **RED 반복 리터럴 `occurrence`·다중 양식 후보·통합 RED MCP 및 포렌식 은닉 자체검사 (`red_service.py`, `red_multimodal.py`, `paper_red_mcp.py`, `paper_stealth_audit.py`)**: `p = 0.04`, `n = 120` 등 여러 번 등장하는 구절을 `occurrence` 순번으로 정확히 겨냥하고, `EvidenceStore`와 대조 검증된 `table-cell`·`chart-point` 다중 양식 후보를 지원합니다. 본문·표·그래프를 함께 다루는 `paper_red_mcp.py`와 생성 PDF의 메타데이터 흔적·쪽 수·비편집 쪽 픽셀 일치·읽기 순서 역전·경계선 이음새를 점검하는 `paper_stealth_audit.py`를 추가했습니다. BLUE에는 변경 계획 없이 생성 PDF 바이트만 전달합니다.
- **전수 참고문헌 검증·초록 대조 및 `ClinicalTrials.gov` v2 등록 대조 (`paper_external_grounding.py`, `paper_clinical_trials.py`, `evidence_blue_v036`)**: 참고문헌의 유령 DOI·키메라(제목·저자·연도 불일치) 서지 검증과 인용 문장↔초록 근거 대조, 본문 `NCT########` 등록번호의 `ClinicalTrials.gov` v2 1차 결과지표 변경·등록 표본수 비교를 구현하고 기존 `v031`~`v035` 번들을 변경하지 않은 채 신규 실험 번들 `app/examples/evidence_blue_v036`로 분리했습니다.

통합 검증에서 앱 등록 Node 스위트 207개 전체 통과, 패키징 검사 13개 통과, 포터블 BLUE(`v033`~`v036`) 및 제어 평가 스위트 52개 통과, Python 계약 스위트 1,049개 통과(7개 환경 건너뜀, 실패 0개), 생산 코드 복잡도(`inventory.mjs --check`, 225개 파일 10,860개 함수 `max CCN = 15`, `>15: 0`)를 확인했습니다(`sourceBuildVerified`는 `false` 유지). 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.61`)으로 업데이트하세요.

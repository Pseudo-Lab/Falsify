# 0.2.0-alpha.67

사람 중심 UI 표면적을 늘리는 대신, 외부·로컬 AI 에이전트가 자율적으로 호출·파이프라인화하기 좋은 **Agent-First 4개 축 1순위 6개 과제**를 전면 구현·통합한 프리릴리스입니다.

- **축 1-① 차세대 BLUE MCP 서버 (`app/local/paper_mcp.py`, `app/local/paper_mcp_bundle.py`)**: 기본 오프라인 상태에서도 즉시 Layer 0 포렌식 감식을 수행하는 `run_blue_sensor`(`digestOnly` 압축 모드 지원), `--supplement PATH` 다중 보충자료 열람·교차 감사(`list_supplements`, `read_supplement`, `audit_supplements`), 그리고 `--oracle` 명시 실행 시에만 활성화되는 `P2` 외부 검증 도구(`verify_references`, `verify_registries`)를 제공합니다.
- **축 1-② 자율형 `BLUE Evidence v0.3.7` 러너 (`app/examples/evidence_blue_v037`)**: 동결된 `v0.3.1`~`v0.3.6` 번들을 수정하지 않고, LLM 호출 전 무비용 Layer 0 정적 포렌식(`SPRITE`/2×2 Fisher/KM 단조성, `supp-*` 보충자료 교차 감사) 및 확장 `P2` 철회 문헌·사전등록(`OSF`/`PROSPERO`/`GEO`/`PDB`) 다이제스트(`<= 18,000`자 상한)를 선제 주입합니다.
- **축 2-① 전양식(Full-Modal) 통합 RED MCP (`app/local/paper_text_span_mutator.py`, `app/local/paper_red_mcp.py`)**: 표·그래프·`/URI` 링크에 더해 네이티브 PDF 본문 구절 무흔적 치환(`list_text_spans`, `text-span` 편집 및 불일치 시 `nearestCandidates`·`recoveryHint` 자가 치유 오류 반환)과 보충자료 변조(`--supplement`, `list_red_supplements`, `supplement-edit`)를 단일 원자 트랜잭션으로 통합하고, 맹검 출력(`pdfBase64`, `blindSupplements`)과 봉인된 정답 원장(`goldLedger`, `baselineOverlaps`)을 엄격히 분리합니다.
- **축 3-①+② 단일 헤드리스 에이전트 JSON CLI 및 내장 스킬 (`app/local/falsify_cli.py`, `.agents/skills/falsify-blue-auditor`, `.agents/skills/falsify-red-injector`)**: `blue scan`(`--digest-only` `< 12 KB` 보장), `red targets`, `red apply`, `blind verify`, `arena score` 명령을 정형 UTF-8 JSON stdout 및 결정론적 종료 코드(`0` 성공, `2` 입력 오류, `3` 은닉·맹검 위반, `124` 시간 초과)로 제공하며, 에이전트가 즉시 로드해 규율을 따를 수 있는 `SKILL.md` 2종을 배포 아카이브에 포함합니다.
- **축 4-① 헤드리스 상보적 진화 아레나 채점기 & 맹검 번들 검증기 (`tools/evaluation/arena_runner.py`)**: 브라우저 없이도 PDF DocInfo/XMP/비링크 주석/AcroForm 위젯 및 보충자료의 정답 누출 여부를 검증(`verify_blind_bundle`, 원본 상속 메타데이터 면제)하고, 다중 BLUE 실행 결과를 봉인 정답 원장 및 `Baseline Guard` 신호와 1:1 이분 매칭해 `W1–W5`·`D1–D7`·`L1–L4` 층화 재현율, `stealthYield`, 다자 `Krippendorff's α`, `확인필요` 선택적 예측(`AURC`), 에이전트 피드백 요약(`feedbackDigest`)을 산출(`evaluate_arena_match`)합니다.

`sourceBuildVerified`는 `false`로 유지됩니다. 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.67`)으로 업데이트하세요.

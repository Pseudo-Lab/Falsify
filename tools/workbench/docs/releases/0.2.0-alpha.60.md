# 0.2.0-alpha.60

실논문 독해·수치 검증(BLUE/MCP), 시각·표·외부 응답 편집(RED), PDF→LaTeX 재구성(`T-0157`) 및 원본 LaTeX 배치 검사(`T-0158`), 단락 오버레이(`paragraph-vendor`) 출처 검증을 통합한 프리릴리스입니다(`0.2.0-alpha.59`의 Linux CI 출처 검증 테스트 실행 래퍼를 교차 플랫폼 Node 배열 호출로 수정해 GitHub Pages 자동 배포까지 검증했습니다).

- **BLUE·읽기 전용 MCP (`D01`–`D06`)**: 반복 로고·아이콘을 `decorative`로 분류해 뒤로 미루고 과학 표·그림을 우선해 최대 24,000자 문맥을 전달합니다. 여러 그리드·다음 쪽 이어짐 표와 단위·각주·위첨자를 묶고, `read_page_text`·`search_text`·`list_references` 읽기 전용 도구를 추가했습니다. 그래프 인쇄 수치(`printedValues`) 대조, 수직·수평 신뢰구간(`ciBounds`) 끝점 분리, 미보정 0 계열 경고를 지원합니다.
- **RED 시각·외부 응답 확장**: 중첩 Form XObject 내부 막대·산점 복제 편집, 축·눈금·문자를 보존하는 어두운 중립색 래스터 곡선 분리, 외부 AI 응답의 구조화 `table-cell`·`chart-point` 파싱과 단계 적용을 연결했습니다. BLUE에는 변경 메타데이터 없이 생성 PDF 바이트만 전달합니다.
- **LaTeX 재구성·원본 호환 (`T-0157`, `T-0158`)**: 그림 번호순 정렬, 참고문헌 항목 줄 분리, 검증된 병합 셀(`\multicolumn`/`\multirow`)과 2단 넓은·긴 표 조판, 선택형 서체 폭 가드를 반영했습니다. 원본 LaTeX `.bbl`·다중 `.bib`·`natbib`/`biblatex`·사용자 매크로 분석과 2단 우측·전폭·다중 쪽 각주 겹침 검사를 추가했습니다. 문서 전체 서체 통일은 기본 비활성(opt-in)입니다.
- **`paragraph-vendor` 동기화 및 교차 플랫폼 CI 검증**: `Shinick-Han/falsify-pdf-editor` `8f3bef6` 모듈과 패치를 동기화하고 `verify-paragraph-vendor-provenance.mjs` 검증을 추가했습니다. WASM 클린룸 소스 재빌드는 수행하지 않았으므로 `sourceBuildVerified`는 `false`로 유지합니다.

로컬 및 CI 검증에서 Node 등록 스위트 207개 전체, 합성 브라우저 스위트, 패키징 검사 13개, Python 998개 통과(7개 환경 건너뜀, 실패 0개), 생산 코드 복잡도(`inventory.mjs --check`, 217개 파일 10,613개 함수 `max CCN = 15`, `>15: 0`)를 확인했습니다. 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.60`)으로 업데이트하세요.

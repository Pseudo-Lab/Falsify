# 0.2.0-alpha.40

가로선 논문 표, 그림–캡션 관계, 같은 기준선 문장 조각과 하단 쪽번호의 구조 손실을 수정했습니다. 표는 원본 영역 이미지와 별도 셀 근거를 보존합니다.

실제 7쪽 샘플을 브라우저와 네이티브에서 7쪽으로 생성했습니다. 출력에서 원본 영역 14개·캡션 9쌍을 확인했고 표 셀 근거 112개를 대조했습니다. 전체 앱 검사 942개 중 935개 통과·7개 건너뜀·실패 0개이며 마지막 집중 검사 57개가 통과했습니다.

그림 번호순 배치, 참고문헌 줄 구분, 원본 벡터 장식은 남아 있습니다. [수정과 확인 범위](../reconstruction-structure-repair.md)를 참조하세요.

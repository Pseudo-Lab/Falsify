# 0.2.0-alpha.69

이번 프리릴리스는 외부·로컬 AI 에이전트가 원자료 재계산, 그림 포렌식, 고난이도(`L3`/`L4`) RED 주입, 보충자료 인용 검증, 무인 RED-vs-BLUE 대결 및 회귀 벤치마크까지 단일 폐루프로 수행하도록 확장한 **Agent-First 3차 4개 축 1순위** 구현입니다. 배포·설치 동작은 이전 버전과 같고 `sourceBuildVerified`는 `false`로 유지됩니다.

- **BLUE 행 단위 원자료 통계 재계산 & MCP 그림 포렌식 (`app/local/paper_raw_dataset_audit.py`, `paper_mcp.py`, `paper_mcp_bundle.py`)**: 첨부 `.csv/.tsv/.json` 원자료에서 표본수(`N`, 결측 제외 `n`), 집단별 `mean ± SD`, `median [IQR]`, `k/n (%)`, 이표본 Welch/Student `t`-검정 및 2×2 정확 Fisher/카이제곱 `p`를 순수 표준 수식으로 재계산해 본문·표 수치와 대조합니다(`raw_dataset_n_mismatch`, `raw_dataset_summary_mismatch`, `raw_dataset_p_mismatch`). 다변량 보정(`aOR`/`aRR`/`aHR`)과 다중 검정 보정(`FDR`/`Bonferroni`/`p_adj`)은 오탐 방지를 위해 자동 면제합니다. 읽기 전용 MCP에 `recompute_raw_supplement`·`audit_figures` 도구를 추가하고 `falsify blue scan --recompute-raw --figure-forensics` 플래그를 연결했습니다.
- **포터블 `BLUE Evidence v0.3.8` (`app/examples/evidence_blue_v038`)**: 동결된 `v0.3.1`–`v0.3.7` 번들을 수정하지 않은 채 원자료 재계산 Triage 다이제스트 주입과 모델 응답 이후 Zero-Drop 누락 복원 + 인용구 실존 검증(최대 1회 수리 호출 후 미검증 인용은 `확인필요`로 자동 강등)을 결합했습니다.
- **RED 난이도 사전 게이트 & 자율형 `RED Injector v0.1` (`falsify_cli.py`, `app/examples/adversarial_red_v01`)**: `falsify red simulate`·`falsify red trace`로 변조 전 Layer 0 발각 여부와 수치 전파 범위를 점검하고, `falsify red apply --min-difficulty L3` 지정 시 기준 미달 변조가 있으면 출력 PDF를 쓰지 않고 종료 코드 `3`(`difficulty_below_minimum`)으로 차단합니다. 신규 포터블 `adversarial_red_v01` 러너는 Baseline Guard → 클레임 전파 추적 → 후보 합성 → 탐지·은닉 검증을 거쳐 맹검 번들과 봉인 정답 원장(`falsify.red-gold-ledger.v1`)을 분리 산출합니다.
- **보충자료 포함 인용 게이트 & 역할별 MCP 구성 (`app/local/blue_report_validate.py`, `falsify_cli.py`)**: `falsify blue validate --supplement PATH ...`가 본문 PDF뿐 아니라 첨부 보충자료 전반에서 인용구 실존 여부를 확인하고 미일치 시 보충자료 파일명·행 번호 기반 `nearestCandidates`를 반환합니다(금지된 RED 키 포함 시 종료 코드 `3`). `falsify mcp-config`는 단독 `--workspace DIR` 및 `--role blue|red|both` 구성을 지원합니다.
- **무인 RED-vs-BLUE 대결·패치 승격 가드 & 10케이스 회귀 벤치마크 (`tools/evaluation/arena_duel.py`, `tools/evaluation/benchmark_suite.py`)**: `falsify arena duel`이 격리된 RED 실행 → 맹검·난이도 게이트 → 클린룸 BLUE 실행 + 인용 검증 → 선택적 클린 Holdout 평가 → 정답 비노출 규칙 증류(`falsify.harness-patch.v1`)를 한 번에 수행하고, `falsify arena apply-patch`가 세대 상한(`max_generations <= 3`)과 Holdout 순수 오탐 증가 롤백 가드(`holdout_fp_regression`, 종료 코드 `3`) 아래에서만 하니스 패치를 승격합니다. `falsify arena benchmark`는 6종 Gold(`W1–W5`, `D1/D2/D3/D4-1/D6/S1`)와 4종 Benign-Trap Holdout(다변량 `aOR`, `FDR` `p_adj`, 좌측 절단 KM, 정합 RCT) 코퍼스로 재현율 하락이나 Holdout 순수 오탐 증가 시 종료 코드 `3`으로 회귀를 차단합니다.

검증은 생산 코드 CCN `max 15`(`>15: 0`), 앱 Node·Cloud API·브라우저 합성 회귀 스위트, 포터블 러너(`v033`–`v038` 및 `adversarial_red_v01`), 평가·벤치마크 스위트 68개, 앱 Python 전체 스위트 1,229개(`skipped=7`, `failures=0`), 패키징 ZIP 수용 검사로 확인했습니다. 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.69`)으로 업데이트하세요.

# 0.2.0-alpha.68

이번 프리릴리스는 외부·로컬 AI 에이전트가 BLUE 감사와 RED 스트레스 테스트를 스스로 이어서 실행하도록 보강한 **Agent-First 2차 4개 축 1순위** 구현입니다. 배포·설치 동작은 이전 버전과 같고 `sourceBuildVerified`는 `false`로 유지됩니다.

- **BLUE 보충 표 재계산 & 그림 포렌식 (`app/local/paper_supplement_audit.py`, `app/local/paper_figure_forensics.py`)**: 보충 표의 행·열 합계와 인쇄 백분율 대 `N`을 재계산해 `supplement_table_sum_mismatch`·`supplement_table_percentage_mismatch`로 보고합니다. 신규 `falsify.figure-forensics.v1` 감사기는 배치 이미지의 dHash/aHash를 비교해 동일 패널 재사용, 좌우 반전, 180° 회전, 중심 크롭 복제를 `pageIndex`·`bbox`·해밍 거리와 함께 찾아내고, 이미 추출된 차트 인쇄값과 주변 본문 수치가 어긋나는 후보도 양쪽 좌표로 제시합니다. `run_blue_sensor`는 `include_figure_forensics` 옵트인일 때만 이 감사기를 호출합니다.
- **RED 탐지 난이도 시뮬레이터 & 클레임 전파 추적 (`app/local/paper_red_detectability.py`)**: `simulate_red_detectability`가 제안된 변조를 메모리에서 적용한 뒤 원본과 편집본의 Layer 0 신호 차집합으로 "정적 센서가 즉시 잡는가"를 먼저 판정하고, 단일 오라클(`L1`)부터 교차 표면 추론(`L3`), Layer 0 감지기 부재(`L4`, `D3`·`S1` 포함)까지 결정론적으로 분류해 노출 위험과 근거를 반환합니다. `trace_claim_propagation`은 하나의 수치·주장이 본문·표·그림·인용·보충자료 어디에 반복 등장하는지 좌표와 함께 매핑합니다.
- **전 오퍼레이션 자가 교정 오류 통일 (`app/local/paper_red_errors.py`)**: `text-span`에만 있던 구조화 오류를 모든 변조 오퍼레이션으로 확장해 `{error, actualValue, nearestCandidates, bbox, recoveryHint}` 규격으로 통일했습니다. 표 셀은 인접 셀, 차트는 시리즈·포인트, `/URI`는 기존 링크 목록, 택소노미 오류는 허용 값 목록을 후보로 제시하며 절대 경로·`cwd`는 노출하지 않습니다.
- **BLUE 리포트 자가 검증 게이트 & MCP 구성 생성 (`app/local/blue_report_validate.py`, `falsify_cli.py`)**: `falsify blue validate --pdf BLIND.pdf --report out.json`이 ① 인용구의 PDF 실존 여부(정규화 일치·근접 후보 포함) ② `candidateLedger` 대비 누락 판정의 Zero-Drop 복원 ③ 아레나 12열 CSV 정규화를 수행하고, 복원 후에도 없는 인용이 남으면 종료 코드 `3`으로 거부합니다. `falsify mcp-config`는 Claude·Codex·Gemini용 stdio 등록 구성을 출력합니다.
- **읽기 전용 다중 문서 MCP 모드 (`app/local/paper_mcp_workspace.py`)**: `python app/local/paper_mcp.py --workspace DIR`이 32편 상한의 읽기전용 스캔을 수행하고, 정답·원장·해설로 보이는 파일명은 내용을 읽지 않고 마스킹합니다. `list_papers`로 목록을 받고 `select_paper`로 한 편을 고르면 기존 읽기 도구가 그 논문을 대상으로 동작하며, 경로 이탈·심볼릭 링크 탈출은 거부되고 페이로드에 절대 경로가 나오지 않습니다. 단일 `--pdf` 동작은 그대로입니다.
- **무인 아레나 라운드 & 정답 비노출 규칙 증류 (`tools/evaluation/arena_round.py`, `falsify arena run-round|distill`)**: 맹검 누출 검사를 먼저 통과한 뒤 임시 클린룸에 맹검 PDF·보충자료만 복사하고 임의의 stdio 에이전트 커맨드를 실행해 다중 라운드를 채점합니다. `arena distill`은 미탐·순수 오탐·판정 플립·RED 조기 발각을 가족·표면·난이도 코드로만 집계해 `falsify.harness-patch.v1` 체크리스트와 차기 RED 브리프를 만들고, 인용·수치·식별자·파일명·`paperId`가 남으면 `distill_scrub_failed`로 실패합니다. 클린룸은 OS 샌드박스가 아니며 이 한계를 라운드 기록과 `docs/arena-round.md`에 명시합니다.

검증은 앱 Python 전체 스위트, 평가 스위트, 포터블 BLUE v0.3.7, Node 스위트, 생산 코드 CCN `max 15` 게이트로 확인했습니다. 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.68`)으로 업데이트하세요.

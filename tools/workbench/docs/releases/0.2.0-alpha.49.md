# 0.2.0-alpha.49

원본 축·눈금·서체·격자를 유지한 채 그래프 모양을 고칩니다. 곡선을 끌어 봉우리·골을 만들고 손잡이로 폭과 위치를 조절합니다. PDF에 독립된 채워진 직사각 막대와 원형 산점은 끝점이나 점을 끌어 바꿉니다. 정밀 좌표는 접힌 영역에 둡니다.

RED에서 **표·그래프·그림 고치기 → 그림 또는 영역 선택 → 그래프 고치기**로 엽니다. **내보내기**를 누르면 현재 편집 PDF를 바로 받습니다. 원본 비교와 되돌리기를 지원하며, 편집을 모두 되돌리면 원본 파일 바이트를 받습니다. BLUE에는 같은 PDF만 전달합니다.

원본 native 선·cubic과 한 단계 공유 Form을 수정합니다. 색 래스터에서는 원본 이미지와 색상 프로필·soft mask를 보존하고 바뀐 부분을 합성합니다. 그림 속에서 가려져 있던 격자는 주변 픽셀로 복원합니다. Form 안의 막대·산점, 패턴 채움과 검은 래스터 곡선 자동 분리는 기존 이미지 교체·고급 도구 범위입니다.

에이전트는 별도 RED 편집 MCP의 prepare/preview/export를 사용합니다. 기존 BLUE MCP는 읽기 전용입니다. 공개 웹과 PC companion을 함께 업데이트하세요.

Windows 로컬 전체 Python922검사 중915통과·7환경 제외, 전체 Node와 UI·패키징 검사가 통과했습니다. 실제 Aside의 곡선/막대 편집·직접 다운로드·되돌리기 원본 SHA·BLUE PDF SHA 일치와 공개 논문17쪽의 편집 범위 밖 보존을 확인했습니다. Windows·macOS·Linux 원격 실행 결과는 이 릴리스의 CI에 남깁니다.

Gaussian 계산에는 MIT ml-peak-shape-generator v5.6.0의 고정 소스와 라이선스를 포함합니다. 사용법과 RED MCP 계약은 [그래프 편집](../paper-chart-shape.md)에 있습니다.

Intel macOS는 upstream 바이너리를 제공하는 pikepdf10.13, 다른 플랫폼은10.17을 고정합니다. CI도 사용자 설치와 같은 requirements 파일을 사용합니다. [upstream 플랫폼 변경](https://pikepdf.readthedocs.io/en/stable/releasenotes/version10.html#platform-support)을 따릅니다.

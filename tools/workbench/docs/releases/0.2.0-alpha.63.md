# 0.2.0-alpha.63

`0.2.0-alpha.62`(경찰 `BLUE` ↔ 도둑 `RED` 상보적 진화 v2 통합본)의 GitHub Actions 브라우저 회귀(`latex-source.browser.cjs`)에서 발견된 BLUE 단계 인덱싱 상호작용을 수정해 GitHub Pages와 로컬 설치본을 일치시킨 후속 프리릴리스입니다.

- **BLUE Layer 0 감식 패널과 시각 단계(`visual-workflow`) 정렬 수정 (`blue-defect-sensor-ui.js`, `blue-defect-sensor.css`)**: `#blue-defect-sensor` 섹션에서 `.role-step` 클래스를 분리해 `visual-workflow.js`의 `[논문, 실행, 결과]` 단계 순서가 밀리지 않도록 바로잡았습니다. 이에 따라 Layer 0 감식 패널은 BLUE 논문 선택 카드 바로 아래에 상시 노출되고, LaTeX 원본 작업대에서 `BLUE로 보내기` 후 요청 JSON(`#doc-blue-request`) 다운로드 경로도 정상 노출됩니다.
- **`0.2.0-alpha.62`의 모든 상보적 진화 v2 기능 포함**: RED 오라클 결함 분류(`D1`~`D4-1`·`S1`) 및 은닉 난이도(`L1`~`L4`)·맹검 누출 원천 차단, BLUE Layer 0 결정론적 감식(`P0`·`P2`) 및 다중 검정 보정 `p`-값 오탐 방지, 외부 BLUE Zero-Drop 2단계 검증 프로토콜, 검수(`H1`) 4분류 정밀 감사 및 상보적 진화 아레나(`A1` · 팀 `score.py` 12열 CSV/Red JSON 호환)가 동일하게 포함됩니다.

`sourceBuildVerified`는 `false`로 유지됩니다. 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.63`)으로 업데이트하세요.

# 0.2.0-alpha.25 — source-preserving deletion

Fixes a short deletion inside a multiline PDF quotation being treated as a cross-line replacement. The native editor can reuse one original text object and font codes, removing the requested characters and shifting only the surviving suffix. New line-break edits and unsupported ownership continue through the existing edit path.

Ordinary generation remains local to the source. Whole-paper new layout is an explicit advanced option; generated file information reports its actual mode and available page counts. An unsuccessful local edit does not silently switch to whole-paper layout.

The reported second-round 36-page paper is an acceptance case: the exact condition deletion stays at 36 pages, all 35 untouched pages match original renders at 72 and 144 dpi, ordered page text reflects only the requested deletion, and links and native typefaces remain. The modified page is serialized by PDFium, so byte-exact or pixel-exact preservation of every unrelated element on that page is not claimed. Larger replacements still use the existing flow capabilities; arbitrary multicolumn growth is not newly supported here.

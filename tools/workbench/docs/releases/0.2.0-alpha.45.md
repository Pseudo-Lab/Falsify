# 0.2.0-alpha.45

그래프 읽기에 PlotTracer 2.6.0의 고정된 공개 계산 코드를 연결했습니다. 자동 눈금 인식이 부족하면 원본 미리보기의 **축·곡선 지정**에서 X1·X2·Y1·Y2와 값을 고르고, 곡선 색을 추가한 뒤 **보정해서 다시 읽기**를 누릅니다. 기본 추출 범위는 선택한 두 축 눈금 사이입니다.

MCP `extract_chart`도 같은 `chartOptions`를 받습니다. 원본 이미지 SHA가 다르면 보정을 적용하지 않습니다. 픽셀·PDF 좌표, 보정 출처와 엔진 커밋은 JSON에 남습니다. 결과는 곡선 샘플이며 평균·신뢰구간 자동 분류는 이번 버전의 기능이 아닙니다.

눈금을 확인하지 못했을 때는 부분 결과와 원본을 유지합니다. DePlot 모델의 숫자를 보정된 좌표처럼 대신 반환하지 않습니다. 새 설치의 그래프 엔진에는 별도 Node 설치나 대형 차트 모델이 필요하지 않습니다. 기존 OCR 환경은 유지하며 MiniRacer 0.14.1을 추가합니다. 기존 DePlot 어댑터 설치가 필요한 경우만 setup에 `--with-deplot`을 사용합니다.

공개 소스와 설치본에는 PlotTracer 원본 소스·라이선스·고정 해시·재현 빌드 스크립트를 포함합니다. 사용자 논문·실험 기록·로컬 설정은 릴리스에 포함하지 않습니다. 실제 배포 완료 여부는 릴리스 및 배포 영수증으로 확인합니다.

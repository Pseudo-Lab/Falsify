# 0.2.0-alpha.26 — 변경 위치 표시와 한국어 근거

- RED 작업대의 원본·수정본에서 변경한 글자를 강조합니다. 삭제한 자리에는 수정본 쪽에 작은 세로선을 표시합니다.
- 편집 목록의 **비교**로 해당 쪽을 열고 양쪽 변경 위치로 이동합니다. **변경 표시**로 강조를 켜거나 끕니다.
- RED 후보의 문장 비교와 다운로드 사본 미리보기에도 변경 부분을 표시합니다.
- **근거 언어**의 기본값은 한국어이며 영어를 선택할 수 있습니다. 새 RED 요청의 공격 근거·근거 관계·검토 메모에 적용합니다. Before·After·근거 인용은 논문 언어를 유지합니다. 기존 응답은 자동으로 번역하거나 재실행하지 않습니다.

강조는 PDF.js의 글자 레이어 위에 표시합니다. 다운로드 PDF, 원본, 편집 기록, BLUE 입력 바이트에는 들어가지 않습니다. 문구가 여러 번 나타나거나 출력 쪽에서 전체 문구를 찾을 수 없으면 임의 위치를 표시하지 않고 문장 비교로 확인할 수 있습니다.

기존 PDF.js/TextLayer를 재사용했으며 새 의존성을 추가하지 않았습니다. 생성 엔진과 글꼴·페이지 배치 경로도 그대로입니다. 한국어 근거의 로컬 생성은 이 버전의 companion이 필요합니다. 수동 전달용 요청에도 선택한 언어 지시가 포함됩니다.

검증: 변경 범위·하이픈/공백·중복/누락·한글/UTF-16 검사, RED 언어 요청/서버 검사, 실제 PDF를 사용하는 데스크톱·모바일 브라우저 회귀 검사. 강조 토글 전후의 PDF 해시와 편집 스냅샷 일치를 확인했습니다. 모델을 호출하지 않았습니다.

# Workbench 0.2.0-alpha.37

저자명처럼 본문과 윗첨자가 섞인 문단에서 단어 하나를 바꾸면 문단 전체가 재배치되고 `expected-text-uncomputable`와 링크 위치 검증 실패가 발생하던 경로를 수정했습니다.

- 바뀐 단어가 하나의 원본 텍스트 객체에 있으면 원래 글꼴과 기준선을 유지합니다. 같은 줄의 뒤쪽 텍스트·별도로 저장된 윗첨자를 함께 이동하며 다른 줄은 유지합니다.
- PDF에서 공백을 글자가 아닌 좌표 간격으로 표현한 경우 그 위치를 보존합니다. 준비한 객체가 원래 서식·가용 공간 조건을 충족할 때 적용합니다.
- 문단 모델과 변경 단어의 유일한 위치를 연결해 페이지의 모든 문자를 대조합니다. 다른 내용의 누락·중복·순서 변경은 계속 실패로 판정합니다.
- 이동한 윗첨자의 링크 영역을 같은 거리만큼 옮기고 목적지는 보존합니다. 좌표를 갖지 않는 페이지 전체 Fit 동작은 같은 페이지임을 확인해 보존합니다.

실제 7쪽 문서의 저자명 편집으로 재현·검증했습니다. 다른 6쪽의 렌더링은 원본과 같습니다. 전체 논문 재구성이나 임의의 혼합 서식 변경을 모두 해결했다는 의미는 아닙니다.

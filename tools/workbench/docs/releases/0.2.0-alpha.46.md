# 0.2.0-alpha.46

RED에 PDF를 넣고 PC에 연결하면 **표·그래프·그림 고치기**가 열립니다.

- **표:** 목록에서 표를 고르고 셀 값을 바꿉니다. 원래 표 선과 다른 셀을 유지하며, 짧은 값은 원래 글꼴과 기준선에 맞춥니다.
- **그래프:** 아래 **스캔·그래프 읽기**에서 그래프를 읽거나 저장된 그래프를 고른 뒤 X/Y 값을 바꿉니다. 선·산점·막대 그래프를 다시 그립니다. 축·제목·계열 색은 접힌 옵션에서 조정합니다. 낮은값·높은값은 직접 입력한 경우만 그립니다.
- **그림:** 목록에서 고르거나 **영역 직접 선택**으로 페이지를 넘기며 범위를 잡습니다. PNG/JPEG 교체, 자르기와 라벨 배치를 지원합니다. 미리보기의 선택 영역만 PDF에 반영합니다.

**PDF에 적용**을 누르면 같은 원본의 표·그래프·그림 변경을 한 파일에 반영합니다. **결과 PDF 저장**으로 받고 **이 PDF로 BLUE 검토**로 전달합니다. BLUE 입력에는 변경 기록을 넣지 않습니다. 변경 전후·좌표·작성 출처·원본/생성본 해시는 자동 기록되며 **변경 기록 JSON 저장**으로도 받을 수 있습니다.

표 칸의 크기는 유지합니다. 긴 문장이 칸에 들어가지 않으면 해당 생성은 완료되지 않고 이전 PDF와 편집을 유지합니다. 그림·그래프의 교체 범위는 이미지로 출력합니다. 그래프 추출값을 평균·신뢰구간으로 자동 분류하거나 임의 과학 도식의 구조를 자동 편집하는 기능은 포함하지 않습니다.

Chart.js 4.6.1과 chartjs-chart-error-bars 4.4.5는 고정된 원본·라이선스·해시 및 재현 빌드와 함께 포함합니다. 공개 웹은 같은 UI를 사용하고 PDF 변경은 연결한 companion에서 처리합니다. 표·그림 편집에는 기존 PyMuPDF와 Pillow를 사용하며 유료 모델을 호출하지 않습니다.

# 0.2.0-alpha.72

이번 프리릴리스는 외부·로컬 AI 에이전트가 체계적 문헌고찰·메타분석(PRISMA·Forest Plot·Cochran's `Q`/`I²`) 및 다중 표 교차 검증, PDF 은닉 텍스트·프롬프트 인젝션 방어와 복합 그림 서브패널·축 왜곡 포렌식(`BLUE v0.4.1`), `.xlsx`·`.ipynb` 무흔적 셀 변조와 `L4` 의미론 플래너(`RED v0.4`), 해시 기반 증거 캐시·`SARIF 2.1.0` 표준 내보내기·스키마 카탈로그(`falsify schemas`), 다자간 `N×M` 아레나 토너먼트(Bradley-Terry/Elo)·이종 BLUE 앙상블 합의·캠페인 체크포인트 재개(`--resume`), 32케이스 회귀 벤치마크(`v4`)까지 단일 헤드리스 루프로 수행하도록 확장한 **Agent-First 6차 4개 축 1순위** 구현입니다. 배포·설치 동작은 이전 버전과 같고 `sourceBuildVerified`는 `false`로 유지됩니다.

- **메타분석(PRISMA·Forest Plot·`Q`/`I²`·합산 효과) & 다중 표 간 표본수 교차 감사 (`app/local/paper_meta_and_table_audit.py`)**: PRISMA 단계별 레코드 산술(`prisma_flow_mismatch`), 연구별 가중치 합(`meta_weight_sum_mismatch`), Cochran's `Q`·자유도·`I²`·`p_het` 정합성(`meta_heterogeneity_mismatch`), 고정효과 역분산 합산 효과치(`meta_pooled_effect_mismatch`, 베이지안·네트워크 메타분석 면제), 표 간 동일 집단 표본수 불일치(`cross_table_sample_size_mismatch`, 하위집단·결측 명시 면제)를 오프라인으로 결정론적 감사하며 `paper_mcp.py`(`audit_meta_and_tables`)와 `falsify blue scan --meta-tables`로 노출합니다.
- **PDF 비가시 텍스트·프롬프트 인젝션 방어, 복합 그림 서브패널·축 왜곡 센서 & 포터블 `BLUE Evidence v0.4.1` (`app/local/paper_pdf_security_forensics.py`, `paper_figure_forensics.py`, `app/examples/evidence_blue_v041`)**: 투명(`Tr=3`)·흰색 위 흰 글씨·초미세 폰트·페이지 밖 텍스트(`hidden_pdf_text_layer`, 전면 스캔본 OCR 레이어 면제)와 에이전트 유도 프롬프트 인젝션(`prompt_injection_directive`, AI 보안 논문 가시 본문 인용 면제)을 탐지하고(`audit_pdf_security`, `falsify blue scan --pdf-security`), 단일 그림 내부의 서브패널 복제·반전(`composite_subpanel_duplicate`) 및 축 눈금 기하 왜곡(`axis_scale_distortion`)을 검사합니다. 동결된 `v0.3.1`–`v0.4.0`을 보존한 채 신규 `evidence_blue_v041`에서 통합 다이제스트와 확정 게이트를 제공합니다.
- **구조 보존형 `.xlsx`·`.ipynb` RED 변조기, `paper_red_mcp` `redBrief` 연결 & 포터블 `RED Injector v0.4` (`app/local/paper_supplement_mutator.py`, `paper_red_mcp.py`, `paper_red_planner.py`, `app/examples/adversarial_red_v04`)**: 비대상 `.xlsx`의 바이트 동일성을 유지하면서 목표 셀·수식만 정밀 교체하는 `xlsx-cell`과 노트북 코드·출력·실행 번호를 교체하는 `ipynb-cell`(`falsify red apply --out-supplement-dir`), `paper_red_mcp` `plan_coordinated_mutation(..., redBrief=...)` 파라미터 통합, `D3`/`S1`/`D5` `L4` 의미론 변조 템플릿을 추가했습니다(`adversarial_red_v01`–`v03` 불변 보존).
- **해시 기반 `EvidenceCache`, 전 센서 워크스페이스 Triage & `SARIF 2.1.0`·스키마 카탈로그 (`app/local/paper_evidence_cache.py`, `paper_sarif_export.py`, `paper_mcp_workspace.py`)**: `(fileHash, supplementSha256s, options)` 키로 반복 스캔 비용을 제거하는 정답·경로 비노출 LRU 캐시(`--cache-dir`), `.xlsx`/`.ipynb` 자동 결합 및 흐름·내부정합성 신호까지 합산하는 `scan-workspace`, GitHub Code Scanning·IDE 호환 `SARIF 2.1.0` 내보내기(`--sarif`), 13개 핵심 스키마 조회 명령(`falsify schemas`)을 지원합니다.
- **다자간 `N×M` 아레나 토너먼트, 이종 BLUE 앙상블 합의기, 캠페인 `--resume` & 32케이스 벤치마크 `v4` (`tools/evaluation/arena_tournament.py`, `blue_ensemble.py`, `arena_campaign.py`, `benchmark_suite.py`)**: 복수 RED×BLUE 라운드로빈 대결에서 Laplace 스무딩 Bradley-Terry 강도·순서 불변 배치 Elo·Pareto 리더보드·`W1–W5 × L1–L4` 히트맵을 산출하는 `falsify arena tournament`, 소수 모델 단독 지적 결함을 삭제하지 않고 `확인필요`로 보존·확정하는 `falsify blue ensemble`, 중단 지점부터 재개하는 `falsify arena evolve --checkpoint-dir --resume --max-total-seconds`를 추가하고, 회귀 벤치마크(`corpusVersion: "v4"`)를 18종 Gold + 14종 Benign-Trap Holdout 총 32케이스로 확장했습니다.

검증은 생산 코드 254개 파일 13,345개 함수 CCN `max 15`(`>15: 0`, 파싱 오류 0), 복잡도 래칫 통과, 앱 Node·Cloud API(57개)·패키징(13개)·브라우저 합성 회귀 전 스위트 통과, 포터블 러너(`v033`–`v041` 66개 및 `adversarial_red_v01`–`v04` 27개 총 93개), 평가·벤치마크 스위트 105개, 앱 Python 전체 스위트 1,361개(건너뜀 7개, 실패 0개) 통과 및 패키징 ZIP 수용 검사로 확인했습니다. 공개 웹과 PC companion을 같은 버전(`0.2.0-alpha.72`)으로 업데이트하세요.

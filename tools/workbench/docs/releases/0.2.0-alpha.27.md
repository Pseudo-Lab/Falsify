# 0.2.0-alpha.27 — 직접 편집창 타이핑 수정

원문을 눌러 연 편집창이 글자를 입력하자마자 닫히던 문제를 수정했습니다. 입력창 내부의 키보드·마우스 이벤트를 원문 선택 처리에서 제외하고, 실제 PDF 글자 선택을 확인한 뒤 편집 이동을 처리합니다.

한글 등 조합 입력 중에는 Escape나 선택 처리로 편집을 확정·종료하지 않습니다. 조합 완료 뒤의 편집 확정과 Escape 취소, 원문 드래그·키보드 선택, 실행 취소와 PDF 생성은 기존 동작을 유지합니다.

기존 문장 전체 채우기 검사에 문자별 실제 키보드 입력, 입력창 안 커서 이동·선택, 여러 줄 입력, 취소·확정 검사를 추가했습니다. 합성 IME 이벤트 검사는 실제 운영체제의 한글 입력기를 실행한 검사와 구분합니다.

이 수정은 브라우저 편집 이벤트 처리에만 적용됩니다. PDF 생성 엔진, 글꼴과 페이지 배치, RED/BLUE harness 실행 계약은 바뀌지 않습니다.

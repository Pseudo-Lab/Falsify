# Workbench 0.2.0-alpha.35

저자 줄의 소속 번호와 인용 번호를 수정할 때 발생하던 혼합 서식 오류를 고쳤습니다.

- 문장 전체를 선택해도 실제 달라진 문자만 찾아 그 문자의 글꼴·색상·윗첨자 위치를 유지합니다.
- 숫자 사이의 쉼표만 색상이 다른 인용 번호도 수정할 수 있습니다.
- 해당 숫자가 독립된 PDF 텍스트 객체이고 주변 글자와 겹치지 않으면 그 객체만 수정합니다. 나머지 저자 줄을 다시 조판하지 않습니다.
- 혼합 서식 판정 오류를 글꼴 파일 누락으로 안내하던 문구를 바로잡았습니다.

실제 7쪽 문서에서 윗첨자 한 자리를 두 자리로 바꾼 결과, 7쪽을 유지했고 나머지 6쪽의 텍스트·렌더링과 전체 링크 대상·영역이 같았습니다. 해당 문서의 별도 전체 텍스트·링크 자체검사 경고는 남아 있으며 모든 서식 조합을 지원한다는 의미는 아닙니다.

로컬 앱 테스트 704개 중 697개 통과, 7개 건너뜀, 실패 0건. 배포 패키지 검사 11개 통과.

원본 논문·사용자 편집·실험 기록은 배포에 포함하지 않습니다. 기존 LaTeX 소스 편집과 PDF 재구성 실험의 지원 범위는 [alpha.34](0.2.0-alpha.34.md)와 같습니다.

# Workbench 0.2.0-alpha.39

PDF-to-LaTeX flow reconstruction now carries source-based publication roles, block sizes and leading, bold/italic runs and evidence-backed inline scripts into typesetting. Footnotes reserve body space. Numeric prose receives observed line-boundary separators while identifiers and formulas retain their source boundaries. STIX Two Math supplements mathematical symbols.

The baseline view adds an explicit AI layout action using the existing source workbench and original/baseline lineage. Uploading a paper or creating a baseline does not start a model. Existing PDF-preserving editing remains the default.

The internal seven-page sample produced seven pages in native LuaLaTeX and browser BusyTeX. Table structure, some source/caption ordering, source-specific icons and full content-fidelity checks remain follow-up work. See [implementation and validation](../reconstruction-publication-roles.md).

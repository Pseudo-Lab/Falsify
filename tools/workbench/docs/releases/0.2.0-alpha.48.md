# 0.2.0-alpha.48

그래프 읽기에 PDF 원본 경로와 WebPlotDigitizer 계산 모듈을 연결했습니다. PDF에 선·3차 곡선 명령이 남아 있으면 원본 끝점과 제어점을 읽고, 이미지 곡선은 Step·XStep과 PlotTracer로 추출합니다. 선택한 축을 그대로 사용하며 사용자가 바꾼 값을 직선 회귀로 되돌리지 않습니다.

짧은 분기선, 비대칭 오차막대, 경계색 선택을 개선했습니다. 교체 이미지가 있는 PDF는 화면에 보이는 곡선을 읽습니다. 측정점·보간점과 원본 경로의 출처, 좌표와 스타일 정보는 JSON과 BLUE 근거에 남깁니다.

사용 순서는 같습니다. RED 또는 BLUE에서 PDF를 넣고 **스캔·그래프 읽기**를 펼친 뒤, 축·곡선이 포함된 영역을 드래그하고 **그래프를 표로 읽기**를 누릅니다. 필요하면 **축·곡선 지정**에서 눈금과 색을 보정합니다. 공개 웹과 PC companion을 함께 업데이트하세요.

로컬 Windows 전체 Python 검사 827개 중 819개 통과·8개 환경별 제외, Node 전체 검사와 변경 영역 10개 검사가 통과했습니다. 합성 PDF의 실제 Aside 입력·OCR·래스터/벡터 읽기·JSON 다운로드도 확인했습니다. macOS 실행 결과는 이 릴리스의 CI에서 확인합니다.

WebPlotDigitizer 포크는 [Shinick-Han/WebPlotDigitizer](https://github.com/Shinick-Han/WebPlotDigitizer)이며 계산 모듈의 고정 커밋·SHA·AGPL 고지를 소스와 번들에 포함합니다.

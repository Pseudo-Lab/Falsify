# 0.2.0-alpha.47

RED의 **스캔·그래프 읽기**가 처음부터 표시되도록 시작 순서를 수정했습니다. alpha.46은 저장된 그래프를 편집할 수 있었지만, RED 통합 화면이 읽기 도구보다 먼저 시작해 새 그래프를 읽는 패널이 누락됐습니다. 미리보기와 읽기 도구를 먼저 불러온 뒤 RED 화면을 연결합니다.

RED에서 PDF를 넣고 PC에 연결한 다음 **스캔·그래프 읽기**를 펼칩니다. 쪽을 고르고 축·곡선을 포함해 드래그한 뒤 **그래프를 표로 읽기**를 누릅니다. 눈금이 필요하면 **축·곡선 지정**으로 보정합니다. 읽은 그래프에서 X/Y 값을 고치고 **PDF에 적용 → 결과 PDF 저장**으로 받습니다.

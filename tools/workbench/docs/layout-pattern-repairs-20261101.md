# AI 배치 편집: 실행·저장·조회 오류 수정

2026-11-01. 기존 배치 편집의 경계 조건에서 재현한 8개 오류 묶음을 수정했다. Cursor 작업자를 전송, 저장·복구, 문서 조회로 나누고 조율자가 통합·독립 재현 검사를 수행했다.

## 수정 내용

| 항목 | 발생 조건 | 수정 후 동작 |

| F01 저장 순서 | 이전 저장의 검증·직렬화가 늦게 끝남 | 같은 실행의 최신 저장 요청이 우선한다. 임시 저장 설정도 같은 대기열을 사용하며 초기화·종료 뒤의 오래된 저장을 막는다. |

통합 검수에서 두 회귀도 수정했다. 유효한 저장이 발행된 뒤 새 저장의 검증이 실패해도 앞선 유효 기록을 삭제하지 않는다. 같은 논문·모델·단계에서 별도로 실행한 요청은 서로 다른 영수증을 남기며, 같은 요청의 복구와 복사된 이력은 중복을 제거한다.

## 검증

기능 커밋 `cbb1ee7`에서 브라우저 번들을 빌드한 뒤 전체 앱 검사를 실행했다. Node 검사 971개 중 964개 통과·7개 건너뜀·실패 0개, 서버 27개와 패키징 11개가 통과했다. 별도의 독립 재현 스크립트 8개도 모두 통과했다. 건너뛴 7개는 별도 컴파일러·글꼴·원본 샘플 환경을 요구하는 기존 배치 검사다.

합성 문서와 모델 응답 대역으로 취소, 접수 거절, 통신 불명확 상태, 저장 경쟁, JSON·ZIP 복원, 긴 인용문 이어 읽기와 응답 크기를 검사했다. 추가 RED/BLUE 실행이나 실제 논문의 모델 재전송은 수행하지 않았다. 상세 실행 영수증은 WorkBite T-0152에 기록한다.

이번 수정의 대상은 실행·저장·도구 조회다. 실제 논문의 재조판 품질과 구분한다. 공개 웹·설치본 교체는 별도 단계다.

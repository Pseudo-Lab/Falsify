# Recomposition runtime vendor

The runtime is built offline with `node app/scripts/build-recomposition-runtime.mjs --node-modules <isolated-node_modules> --static-fonts <static-font-proof-directory> --font-sources <font-source-directory>`. The input package directory must contain `@myriaddreamin/typst.ts` and `@myriaddreamin/typst-ts-web-compiler`, both exactly 0.7.0. The app's existing esbuild 0.28.2 and MuPDF 1.28.1 are used. No package install or network access occurs. The compiler WASM SHA-256 is pinned by the build; its byte-for-byte hash and each distributed font hash are in `app/dist/recomposition-vendor/manifest.json`. The output URLs are relative to the manifest, including when served under a repository subpath.

Typst.ts and the web compiler are Apache-2.0: https://github.com/Myriad-Dreamin/typst.ts; package license is included as `LICENSE_TYPST_APACHE`. The compiler module and WASM are from npm version 0.7.0. The worker uses the existing MuPDF vendor at `../browser-pdf-vendor/` (AGPL-3.0-or-later; see its NOTICE and manifest) and existing PDF.js under `../vendor/`.

The eight Noto Serif and Noto Sans static faces derive from Google Fonts commit `e7db6ca603fd4862010383ff17ffd6cc4ffac1c0`, https://github.com/google/fonts/tree/e7db6ca603fd4862010383ff17ffd6cc4ffac1c0/ofl. They were instantiated from variable fonts with fonttools 4.66.0 at width 100 and weights 400 or 700, with regular/italic source variants and static name/style metadata. They are modified fonts, not the upstream variable files. `static-font-provenance.json` records source and output hashes, axis values, names, coverage and notices per face. OFL 1.1 notices are included for both families. Static fonts are used because the previous actual Typst proof selected regular for variable bold.

Four Liberation Sans faces come byte-for-byte from the existing PDF.js `dist/vendor/standard_fonts` distribution; their license is included as `LICENSE_LIBERATION`. Their individual hashes are in the runtime manifest. The font set is finite and does not guarantee coverage for every paper or language.

Run the focused tests with `node app/tests/recomposition-vendor.spec.mjs --node-modules <isolated-node_modules> --static-fonts <static-font-proof-directory> --font-sources <font-source-directory>`. They require Python with PyMuPDF to inspect the actual generated PDF font resources. They exercise a real compiler and compiled WebAssembly.Module, not a real-paper roundtrip or browser activation.

# 0.2.0-alpha.17

직접 편집 동선을 정리했습니다. 원문의 문단이나 변경 목록을 눌러 수정 내용을 열고, `적용`한 뒤 `수정본 미리보기 만들기`로 결과를 확인합니다.

- `After 수정` 버튼 제거, 변경 항목에서 바로 재편집.
- 원문 옆 편집창과 작은 화면의 일반 배치, 키보드 문단 선택.
- 문단 준비 상태 표시와 원본별 쪽 분석 결과 재사용.
- 빈 편집 도구, 초안·파일 정보·외부 AI 입력의 노출 정리.
- RED/BLUE 실행 역할 표시와 PC 연결 바로가기.
- 중복 BLUE 실패 안내 정리, RED 접수 상태 조회 추가.
- 화면과 설명서의 버튼 이름 동기화.

PDF 편집 엔진과 고정 WASM은 alpha.16과 같습니다. 원문 위치, 실행 동의, 출처, 재시도, 팀 공개 경계는 유지합니다. 공개 웹 변경은 기존 PC companion을 종료하거나 교체하지 않습니다.

자세한 판단 근거는 [직접 편집 UX 개선](ux-editor-refinement.md)에 있습니다.

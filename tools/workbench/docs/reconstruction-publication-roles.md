# 재구성본의 문서 역할과 서식

2026-11-01 구현. 문단 흐름 재조판 경로에 적용한다. 원본 배치 편집은 기존 경로를 사용한다.

PDF에서 관측한 글자 크기·굵기·기울임·위치를 조판에 연결했다. 제목, 저자, 소속, 초록, 절 제목, 각주, 날짜 등의 역할을 원문과 좌표에 근거해 제안한다. 각주는 LaTeX의 각주 영역에 배치해 본문 공간을 예약한다. 명시적으로 선택한 문서 서체·크기 설정은 유지한다.

숫자가 포함된 문단도 줄 경계의 공백을 복원한다. 원래 문자 범위는 별도로 보존하고, URL·DOI·수식·하이픈 경계에는 같은 규칙을 적용하지 않는다. 줄 안의 관측된 작은 글자를 일괄 첨자로 바꾸지 않고 주변 본문과의 크기·높이 차이를 함께 사용한다. STIX Two Math로 수학 기호를 보충한다.

기준본 화면의 **AI로 배치 다듬기**는 현재 기준본과 원본의 계보를 기존 소스 작업대로 넘긴 뒤 AI 배치 도구를 실행한다. 파일 입력이나 기준본 생성만으로 모델을 호출하지 않는다. 연결이 없으면 기준본 화면에 머문다. 원본 변경·취소·중복 클릭으로 오래된 기준본을 실행하지 않도록 검사한다. AI 후보는 기존 실행 기록과 별도로 보관한다.

## 확인한 범위

- 합성 PDF에서 원본 범위 보존, 공백·기울임·첨자 복원, DOI·수식 보호를 검사했다.
- 제목·저자·초록·절 제목·각주와 사용자 조판 설정의 우선순위를 검사했다.
- 원본·기준본의 동일한 쌍을 넘긴 뒤에만 AI 시작을 호출하고, 오래된 로드는 실행하지 않는지 검사했다.
- 실제 내부 7쪽 샘플은 네이티브 LuaLaTeX와 브라우저 BusyTeX에서 각각 7쪽으로 생성됐다. 브라우저 PDF 다운로드를 확인하고 네이티브 출력 7쪽을 모두 렌더링해 검토했다.

## 남은 품질 작업

표 구조가 없는 추출 결과는 아직 세로 목록으로 조판될 수 있다. 일부 원문의 ActualText·그림 캡션·인용 경계에 순서나 연결 문제가 있고, 원문 전용 아이콘 글꼴의 문자가 빠질 수 있다. 내부 샘플의 원시 숫자 토큰 차이는 67개로 남아 있다. 이 비교에는 래스터 그림의 텍스트, 첨자의 추출 순서와 단어 경계가 섞여 있으므로 과학적 값 변경 67개로 해석하지 않는다. 전체 내용 복원 검증은 완료되지 않았다.

샘플 PDF·원문·생성본·실험 기록은 비공개 로컬 검증 폴더에 보관한다. 공개 웹 배포와 설치본 교체는 이 구현과 별도다.

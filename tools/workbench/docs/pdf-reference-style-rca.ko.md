# 인용 번호 편집의 서식 판정 오류

`AMBIGUOUS_STYLE`은 글꼴 파일이 없다는 뜻이 아니다. 편집 계획 단계에서 글꼴·크기·색상·가로 배율·윗첨자 높이 등을 포함한 여러 서식을 하나의 변경에 연결하지 못했다는 뜻이다. 기존 화면 문구는 이를 글꼴 선택 실패로만 표시했다.

같은 글꼴·8pt·같은 윗첨자 높이의 `2,3`에서 숫자는 파란 링크, 쉼표는 검정일 수 있다. 공백 단위로는 단어 하나지만 두 서식으로 판정되어 `35`로 합치는 변경이 거절됐다. 대체 글꼴 카탈로그에 도달하기 전 실패하므로 글꼴을 더 설치해도 해결되지 않는다.

수정은 숫자들의 서식이 모두 같고, 구분 문자의 차이가 채움 색상뿐인 숫자 목록/범위로 한정한다. 새 숫자는 기존 숫자의 서식을 잇는다. 완전히 선택된 원본 텍스트 객체와 원래 영역을 확인할 수 있으면 해당 객체만 수정하며 주변 문단을 다시 조판하지 않는다. 실제 글꼴·크기·높이 또는 숫자끼리의 서식이 다르면 이 규칙으로 추정하지 않는다.

합성 회귀 검사에서는 원본 객체 수정, 숫자 표현, 원본 영역 밖 픽셀과 다른 쪽의 완전 보존 및 같은 엔진 자체검사를 확인한다. 로컬 실제 7쪽 사례는 7쪽을 유지했고 나머지 6쪽의 텍스트·렌더링은 동일했다. 편집한 쪽의 글자/순서 검사도 통과했다. 기존 링크 검증의 미확인 경고는 별도로 남아 있어 전체 품질 통과로 표시하지 않는다. 원본 논문과 생성 파일은 Git에 넣지 않는다.

전체 Node 검사: 700개 중 693개 통과, 7개 건너뜀, 실패 0. 패키징 검사 11개 통과. 이 문서는 로컬 수정/검증 기록이며 공개 배포를 뜻하지 않는다.

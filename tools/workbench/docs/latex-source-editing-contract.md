## Shared values

All modules ESM. Byte fields are owned Uint8Array copies; text is UTF-8 for v1. New source data never enters the strict paper-edits.v1 schema without an explicit adapter. Use existing SHA256 helper paragraph-pdf-crypto.mjs/hex, existing fflate, existing generation semantics. Public errors have code/message/details without document dumps.

SourceProject: {schema:'falsify.latex-project.v1', id:SHA256, revision:nonnegative integer, origin:'original-source'|'reconstructed-pdf', mainFile:string|null, engine:'pdflatex'|'xelatex'|'lualatex', files:[{path:normalized relative POSIX string,bytes:Uint8Array,sha256:SHA256}], sourcePdfHash?:SHA256}. id hashes sorted path+content digests+mainFile+engine+origin. No timestamps in identity. Preserve exact original bytes and imported files. Applying changes returns a new project; never mutates original.

SourceNode: {id,path,kind:'text'|'superscript'|'subscript'|'math'|'footnote'|'citation',start,end,contentStart,contentEnd,text,sourceText,displayText}. Offsets are UTF-16 offsets in decoded UTF-8 file; start/end include syntax; contentStart/contentEnd locate editable content. Surrogate/multibyte conversion tested. id includes project.id,path,range,kind. Unknown macros are preserved; no guessed expansion or broad formatter.

SourceAnchor: {projectId,nodeId,path,start,end,kind}; bound to current project identity. SourceChange: {id,before,after,anchor,enabled:true,kind:'text'|'superscript'|'subscript'|'math'|'footnote'|'citation',mode:'content'|'display-override',provenance:{origin:'human'|'external-ai',responseId?:string}}. Overlaps require one chosen alternative; whitespace normalization must map to source. Empty after means deletion. Source code mode is explicit; text mode escapes LaTeX reserved chars without corrupting math/source syntax.

CompileRequest: {project,signal?,onProgress?,engineManifest?,key?}. CompileResult: {schema:'falsify.latex-artifact.v1',success:boolean,pdfBytes?:Uint8Array,pdfHash?:SHA256,projectId,key,engine,engineManifest,sourceMap?:object,synctex?:Uint8Array,diagnostics:[{code,message,severity:'info'|'warning'|'error',path?,line?}],timings:{totalMs,cold?}}. Actual compile failure cannot return success:true or stale pdf as current. BLUE receives only a PDF File made from actual pdfBytes, never project/sourceMap/changes. No generated attack watermarks or source attachments in PDF. Bound compiler work to owned virtual FS, no shellEscape/user JS handlers by default. No user source/figure/font uploads to package service.

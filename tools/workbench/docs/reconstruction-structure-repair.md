# 재구성 구조 손실 수정 — 2026-11-01

alpha.39에서 확인한 표·캡션·문장 조각·쪽번호의 구조 손실을 수정했다. 원본 PDF와 실행 기록은 비공개 로컬 자료로 유지한다. 공개 배포와 설치본 교체는 별도 단계다.

## 변경

- 가로선만 있는 논문 표를 표 제목, 선 범위, 정렬된 행으로 찾는다. 숫자에 단위가 붙어 있어도 셀을 유지한다. 표 제목과 표 전체를 원본 영역 이미지로 보존하고, 원문 문자 범위에 연결한 셀 구조도 유지한다. 이 경로의 기준본 표는 이미지이며 임의 병합 셀 편집을 지원한다는 뜻은 아니다.
- 캡션의 유형을 추출 결과에 유지한다. 근거로 연결된 그림과 캡션은 평탄한 배열에서 떨어져 있어도 같은 float로 조판한다. 본문의 `Figure N shows…` 같은 문장은 캡션으로 분류하지 않는다. 가까운 그림이 둘일 때는 같은 쪽의 명확한 캡션 방향을 근거로 삼는다.
- 같은 기준선의 짧은 문장 조각을 본문에 유지한다. 관찰된 줄 폭을 넘는 인접 단은 합치지 않는다. 문자 범위는 그대로 보존하고 실제 좌표로 확인되는 공백만 복원한다.
- 하단 중앙의 작은 현재 쪽번호는 반복 문자열이 없어도 furniture로 분류한다. 본문 숫자는 유지한다.
- 출력 PDF의 이미지 픽셀과 캡션 위치를 검사한다. 표 셀의 관찰 문자열은 원문 문자 범위와 대조한다. 검사는 Worker에서 실행하며 원본·출력 해시에 연결한다. 실패해도 생성 PDF 다운로드는 유지한다.
- 화면에는 영역 보존, 캡션 연결, 표 보존 결과를 표시한다. 표를 이미지로 보존하면 원시 텍스트 추출의 숫자 차이가 생기므로 해당 대조는 상세 기록에 유지한다.

## 남은 범위

그림 번호 순서를 따르는 전역 float 배치, 참고문헌 항목의 줄 구분, 원본 전용 벡터 로고·장식 복원은 남아 있다. 표의 원본 영역 보존은 출력 픽셀로 확인했지만 일반 PDF 텍스트 추출에는 표 셀이 나타나지 않는다. 표 내용 변경 후의 네이티브 재조판, 임의 병합 셀, 긴 표는 이 수정의 확인 범위가 아니다. 문서 전체의 시각적 동일성과 읽기 순서도 이 검사만으로 보증하지 않는다.

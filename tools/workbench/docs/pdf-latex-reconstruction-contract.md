# PDF-to-LaTeX reconstruction: P0 contract proposal

Status: accepted for the first reconstruction implementation, 2026-10-30; source base `30e2bd474edf521ad22248c22530ba1ff890aabe`. Original-source browser checks cover actual WASM compile, external mixed-run edits, highlights and resize, download, archive restore, BLUE file identity without auto-run, and return to the PDF editor. The source-record projection passes the existing Confluence archive codec locally; a team publication roundtrip was not performed. No reconstruction implementation or end-to-end success is claimed yet. Root owns integration. The existing source contract and PDF editor remain authoritative.

## Objective and first supported scope

Produce an **editable reconstruction**, never describe it as recovered original TeX. The first candidate scope is a digitally born, unencrypted, horizontal Latin-text PDF with verified identity page geometry, simple single-column paragraphs and headings, and locally available compiler packages/fonts. Exact text and numbers must survive; multi-column, complex furniture, scanned pages, uncertain math, nested/merged tables, and unresolved links require explicit review or unsupported status. A bounded region crop may preserve an otherwise unrecognized figure or equation as a non-editable asset; whole-page image-only output is not success. A successful compile alone is not reconstruction acceptance.

All processing is offline in the browser, with owned byte copies, cancellation and finite resource budgets. Do not upload private PDFs or use paid services. Preserve evidence including ambiguities, and do not correct scientific content or contradictions. A baseline correction is distinct from a RED change.

## Existing capabilities and limits at base

| Need | Existing API and observed boundary |
| --- | --- |
| Text, line, character, image occurrence, geometry | `paper-document.mjs`: `readDocument({file,fileHash,signal})` accepts File/bytes, checks SHA and 25 MiB, uses MuPDF structured text. `normalizeDocument({sourceSha256,pages,signal})` produces `falsify.paper-document.v1`; source page text ranges, lines, character boxes/styles, image page/occurrence/transform and decoded PNG/mask are observations. Frame is `mupdf-display`; original page mapping is explicitly unverified. Nonzero page origin is rejected. PDF extraction is not semantic truth. |
| Paragraph, heading, columns, furniture, figure and caption proposals | `paper-flow.mjs`: `buildPaperFlow(document,{drawings=document?.drawings || [],links})` returns `falsify.paper-flow.v1` with `items`, `relations`, `fragments`, `regions`, diagnostics and source hash. Its heuristics, splits and artwork ownership are proposals, not proof. `paragraph-pdf.mjs` `inspectPage(request)` returns PDFium paragraph/runs and skipped diagnostics; `planDocumentLines`/`compactDocumentFlow` in `paragraph-vendor/document-flow.mjs` are editing/flow tools, not general structure parsers and explicitly reject some table/column cases. |
| Assets, clips, alpha, fonts | `paper-source-assets.mjs` `readSourceAssets({bytes,document,regions=[],signal})` gives source-bound assets, fonts, drawings, diagnostics. Region crop renders bounded page content at 216 dpi as SVG containing raster PNG, retaining rendered clip/mask/blend appearance, **not editable vector objects**; crop contamination and fidelity need checks. Resource font bytes may be subsets; permissions and coverage are unknown. `paper-asset-spans.mjs` `resolveOutputAssetSpans({bytes,mupdf,flow,blockSpans})` matches output occurrences with strict transform, alpha and clip conditions; it is output evidence, not a source figure extractor or proof for complex clips. |
| Tables | `table-adapter.mjs` `detectSourceTables({sourceBytes,sourceSha256,revision,mupdf,readPages})` returns hash-bound `falsify.source-tables.v1` structure hints with cells/edges; rotated pages are skipped, unruled text-only tables can be missed. `selectTableCell(model,{tableId,cellId,sourceSha256,revision})` requires an issued model and can return unsupported for ambiguity or multi-run cells. Candidate confidence is not structural proof. |
| Links and references | `paper-source-links.mjs` `readSourceLinks({bytes,document,signal})` inventories link occurrences, source ranges, targets and verified display frames; absent/ambiguous geometry stays unresolved. `paper-link-plan.mjs` `buildLinkPlan({document,flow,links,edits=[]})` is existing recomposition planning, not bibliography semantics. `latex-reference-policy.mjs` `buildReferencePatch(project,node,{after,mode})` works on existing source nodes; it cannot recover citation keys or footnote bodies from a PDF. |
| Inline math and scripts | `paper-flow.mjs` inline fragments preserve source character views and joiners, not math recognition. `latex-source-model.mjs` `analyzeLatexSource(project)` recognizes math already present in TeX; it does not infer TeX from PDF glyphs. Baseline/font-size evidence can suggest script candidates but cannot establish equation syntax or semantic links. |
| Compiler/project | `latex-project.mjs` `createLatexProject({files,mainFile,engine,origin,sourcePdfHash})` creates the existing source project; `latex-compiler-adapter.mjs` provides `createLatexCompiler().compile(request)`. Verify actual engine assets, package coverage and licenses in integration; do not infer availability from the interface. Existing PDF.js `getTextContent()` is used in `latex-workbench.mjs`; it is an independent text observation, not an equation parser. |

`browser-pdf.mjs` `prepare(request)` has a zero-based text `anchor.occurrence` for disambiguating edits; it is not a figure occurrence API. Do not equate this ordinal with image occurrences or detector order. Coordinate conversions must be explicitly proven before joining `top-left-page` table data with `mupdf-display` observations; the first scope may refuse nonidentity frames.

## Proposed shared data contract

All proposed APIs below are new, not currently exported. ESM; deterministic output for identical bytes, options and engine versions. SHA-256 fields are lowercase hex; bytes are copied; page indices are zero-based; ranges are half-open UTF-16 offsets into exact extracted page text, **not** TeX source offsets. Geometry is finite `[x0,y0,x1,y1]` in points, with a declared frame and page transform; reject or retain unresolved mappings when frame proof is missing. IDs bind source hash, kind and source occurrence/range, not display text alone. Public errors contain fixed codes and no document dumps.

```ts
type EvidenceRef = {sourceSha256:string, pageIndex:number,
  frame:'mupdf-display', bbox:[number,number,number,number],
  blockId?:string, range?:{start:number,end:number}, occurrence?:number};
type Diagnosis = {code:string, severity:'info'|'warning'|'error', pageIndex?:number, itemId?:string};
type Item = {id:string, kind:'paragraph'|'heading'|'figure'|'table'|'math'|'footnote'|'citation'|'furniture'|'unknown',
  evidence:EvidenceRef[], status:'observed'|'proposed'|'confirmed'|'unsupported',
  text?:string, order?:number, assetId?:string, reason?:string};
type Relation = {kind:'caption'|'footnote'|'citation'|'link', from:string, to:string,
  status:'proposed'|'confirmed'|'unresolved', evidence:EvidenceRef[]};
type ReconstructionModel = {schema:'falsify.pdf-latex-reconstruction.v1', sourceSha256:string,
  pages:{pageIndex:number,width:number,height:number,frame:'mupdf-display',transform:number[]}[],
  items:Item[], relations:Relation[], assets:Asset[], diagnostics:Diagnosis[]};
type Asset = {id:string, evidence:EvidenceRef[], representation:'region-raster'|'image',
  bytes:Uint8Array, mediaType:string, sha256:string, editable:false, reason:string};
type SourceBinding = {itemId:string, projectId:string, path:string, start:number,end:number,
  evidence:EvidenceRef[], status:'exact-text'|'reviewed'|'review-required'|'noneditable'};
```

Relations are claims with evidence, never inferred from a matching printed number alone. `confirmed` requires a documented source proof or explicit user review, not a heuristic score. Retain source crop evidence for unsupported regions and keep content ownership exclusive: no figure-label duplication into prose. A crop is valid only when the bounded source region is known and does not silently include unrelated content; otherwise report unsupported. Do not export external font bytes absent permission/coverage review. Keep original PDF bytes and all maps privately; no source/maps in BLUE inputs.

## Independent worker boundaries

Interfaces use exact names below; root coordinates any shared contract change. Workers create only their named source/tests and synthetic fixture files, and do not edit shared registries, UI, package manifests, generated files or other workers' modules. Their outputs are data, not automatic authorization to generate an attack.

**P1 — source evidence and reading order.** Own `app/src/pdf-latex-evidence.mjs`, `app/tests/pdf-latex-evidence.spec.mjs`. `async extractReconstructionEvidence({bytes,sourceSha256,signal}={}) -> {document,flow,links,assets,diagnostics}` wraps the existing readers with immutable copy/hash checks and explicit bounds; evidence uses the declared frame. `buildReconstructionModel({document,flow,links,assets}) -> ReconstructionModel` maps proposals, preserves exact ranges and rejects stale/ambiguous provenance. Distinguish repeated furniture from actual body and retain uncertain items. Columns may be proposed only where validated, not silently reordered. No source generation.

**P2 — structured regions.** Own `app/src/pdf-latex-regions.mjs`, `app/tests/pdf-latex-regions.spec.mjs`. `async enrichReconstructionRegions({model,bytes,mupdf,revision,signal}={}) -> ReconstructionModel` uses table/asset inventories with hash/frame validation, exclusive ownership and bounded crops. Structured tables are editable only after every emitted cell, span and reading order is proved or reviewed; otherwise preserve a labeled non-editable region or mark unsupported. Do not claim vector preservation from raster crop, and do not silently flatten complex clips, transparency or mixed artwork. No P1 file edits.

**P3 — semantics and serialization.** Own `app/src/pdf-latex-serialize.mjs`, `app/tests/pdf-latex-serialize.spec.mjs`. `serializeReconstruction({model,decisions=[],engine='pdflatex'}={}) -> {status:'ready'|'needs-review'|'unsupported',files:{path:string,bytes:Uint8Array}[],mainFile:string|null,bindings:SourceBinding[],diagnostics:Diagnosis[]}`. Escape plain text correctly, preserve Unicode only where the selected compiler supports it, use approved local assets/packages, and never generate guessed math/citation keys. Script, equation, footnote or citation candidates require reviewed source transcription or a bounded non-editable fallback. `decisions` are explicit per item with source hash, chosen transcription/relationship and evidence; stale decisions fail. Output bindings are computed from actual emitted UTF-8-decoded TeX UTF-16 offsets and later bound to the resulting project ID, not conflated with PDF ranges. Unsupported inputs cannot yield `ready`.

**P4/root — integration and baseline.** Root owns `createLatexProject` invocation with `origin:'reconstructed-pdf'`, `sourcePdfHash`, project-ID binding, compiler, UI, persistent ledger and experiment wiring. Store immutable original PDF/hash, pre-attack reconstructed project and compiled baseline/hash, source-to-PDF evidence and reconstruction differences/user corrections separately from subsequent RED changes and attack artifact/hash. Compile baseline and attack under the same recorded engine manifest and assets. BLUE receives only the explicitly selected PDF. A failed/cancelled compile cannot reuse an earlier artifact as success.

## Synthetic fixtures and acceptance gates

Generate labeled synthetic PDFs locally from checked-in TeX projects, plus expected sidecars; do not commit private papers. Separate: (1) simple single-column body/heading with repeated numbers, Unicode/escaping and deliberate contradiction; (2) two columns and repeated header/footer; (3) figure with shared image occurrences, vector labels, alpha, clip and unrelated nearby text; (4) ruled/unruled, merged and repeated-value tables; (5) superscript/subscript, inline/display math, footnote and citations with and without PDF links; (6) rotated/cropped, encrypted, scan-only, malformed and cancellation cases. Ground truth is the synthetic source, not assumed recovered source. Use existing tests `paper-flow.spec.mjs`, `paper-academic-flow.spec.mjs`, `browser-pdf-crop-table.spec.mjs`, `latex-source-project.spec.mjs` as references, and add independently meaningful tests for each owned API.

Acceptance: deterministic hash-bound evidence, no input mutation, range/geometry and occurrence disambiguation, preserved exact text/numbers and contradiction, correct order or explicit uncertainty, no duplicate figure labels/furniture, honest asset/clip/alpha status, complete cell/span validation or unsupported, and no fabricated equation/reference. Verify invalid/stale hash, frames, budgets, cancellation and missing engine/assets fail closed. Compile actual emitted project offline, then compare baseline PDF against original with independent extraction and bounded visual evidence: report omissions/additions, number mismatches, item counts, position deltas, unreadable glyphs and unsupported coverage separately. Assert no-op baseline vs RED artifact lineage; user corrections update baseline lineage, never become attacks. Thresholds and corpus coverage must be fixed by root before declaring a product gate passed. Passing fixtures cannot establish general publisher support.

## Search decision and remaining gaps

Local search covered source, manifests, existing models and tests; `.codegraph/` is absent. Installed versions are MuPDF 1.28.1 and PDF.js 6.4.299. Reuse/wrap existing MuPDF document, flow, table and link APIs; compose with the existing compiler after its actual asset gate. PDF.js documents [`getTextContent` and `getOperatorList`](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib-PDFPageProxy.html), useful for independent observation but not semantic math reconstruction. [Nougat](https://github.com/facebookresearch/nougat) produces markup from learned recognition, not original source or guaranteed exact content; its [model license is CC BY-NC 4.0](https://github.com/facebookresearch/nougat/blob/main/LICENSE-MODEL.md), and no weights, browser viability or inference were tested. The existing optional [Docling adapter](pdf-structure-adapter.md) is a local structure hint, not a bundled browser engine; its real conversion and models were not tested here. Neither alternative currently meets the offline browser, exact-evidence and no-new-model gates. No external dependency is selected; this is a provisional architecture, not an exhaustive survey.

Missing capabilities include reliable mathematical recognition, semantic footnote/citation linking, faithful isolated vector/complex-compositing export, authoritative table spans, font rights/coverage, and a verified source-to-reconstructed-output mapping. A typed unsupported result and reviewable evidence are required until these are implemented and verified. No model was downloaded, private document uploaded, or browser conversion executed for this proposal.

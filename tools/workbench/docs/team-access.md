# 팀 접근과 공동 기록

현재 원격 영구 보관은 Confluence뿐입니다. 개별 Workbench 계정, 초대 코드, D1 비공개/공유 절차는 현행 운영 경로가 아닙니다. 기존 기록은 보존되며 자동 이관되지 않습니다.

1. 본인 Atlassian 계정과 Falsify 보관 위치 접근 권한으로 Confluence에 연결합니다.
2. 로컬 사례나 Harness를 골라 내용을 확인하고 팀 공개에 동의한 뒤 저장합니다. 팀 공개는 해당 보관 위치에 접근할 수 있는 팀을 뜻합니다. PDF 바이트는 포함되지 않지만 추출문과 응답 등은 포함될 수 있습니다.
3. 팀 기록은 임시 검수로 열립니다. 새 검수는 닫기, 연결 해제 또는 새로고침 전에 명시적으로 게시해야 하며 임시 보기는 최대 12시간입니다. 로컬 기록은 자동 병합 또는 게시되지 않습니다.

연결과 열람은 모델을 실행하지 않습니다. Harness 미리보기 후 등록과 실행은 별도입니다. [자세한 사용법](confluence-use.md) · [보관 계약](confluence-storage-contract.md) · [Harness 계약](harness-contract.md#선택형-공동-기록)

# 0.2.0-alpha.18

RED 후보를 선택하고 After를 고친 뒤 `PDF 다운로드`를 누르면 선택한 변경을 적용해 바로 파일을 받습니다. 위쪽 작업대를 다시 찾아갈 필요가 없습니다.

- 다운로드는 PDF 한 개입니다. 변경 계획 JSON은 별도 버튼으로 저장합니다.
- 로컬 파일 다운로드용 추가 확인 체크를 제거했습니다. AI 실행·팀 공개 동의는 각각의 작업에 유지합니다.
- 후보의 근거·불확실성과 엔진 설명은 펼쳐서 볼 수 있습니다. 원문과 수정 내용은 바로 편집합니다.
- 알려진 Falsify 학습용 표시와 배경 띠가 별도 PDF 객체로 들어 있는 원본은 편집 전에 해당 객체만 제거합니다. 원본은 보존하며 제거 내역과 해시 연결은 변경 기록에 남깁니다.
- BLUE에 전달하거나 내려받는 PDF는 `paper.pdf`라는 이름을 사용합니다. RED 계획·정답·제거 내역은 PDF에 넣지 않습니다.
- PDF.js와 PDFium이 다르게 읽는 일부 줄끝 표기는 원본 줄 위치가 입증되는 경우에 한해 연결합니다.

본문에 실험 표시가 합쳐져 있는 기존 수정본은 원본 PDF로 다시 작업해야 합니다. 다단 문서의 긴 수정과 글꼴·레이아웃은 엔진 지원 범위를 따르며, 출력 검사 상태는 결과 기록에 보존합니다.

실제 36쪽 사례의 첫 후보는 원본 인용 매칭을 통과하지만 9줄에서 10줄로 늘어나는 다단 배치가 아직 지원되지 않습니다. 두 후보를 모두 적용한 실파일 검증은 통과하지 않았으며, 재배치와 단어 간격 보존은 WorkBite T-0141에서 추적합니다. 데스크톱·모바일의 직접 다운로드, 표시 제거와 미선택 내용 보존은 별도 합성 PDF로 검증했습니다.

# Workbench 0.2.0-alpha.22

## PDF에서 바로 수정하기

RED에 PDF를 넣고 문단을 클릭하거나 글자를 드래그하세요. 선택한 위치에서 입력할 수 있습니다. 다른 곳을 누르거나 쪽을 옮기면 저장되고, Escape는 입력을 취소합니다. 원래 문장과 바뀐 문장, 위치, 작성 출처는 자동으로 기록됩니다.

긴 변경은 **전체 논문 재조판**을 선택하고 **수정본 미리보기 만들기**를 누르세요. 재조판은 본문과 그림을 새 페이지 흐름으로 배치합니다. 쪽수가 달라질 수 있으며 출력 쪽은 미리보기에서 따로 탐색합니다. 생성 중에는 취소할 수 있습니다. 미리보기와 다운로드는 같은 생성 파일을 사용합니다.

파일 정보에서 출력 검사 결과를 볼 수 있습니다. 생성된 PDF는 검사에서 확인 항목이 있어도 다운로드할 수 있습니다. 생성 자체가 실패하면 입력한 변경과 마지막 생성본을 유지합니다.

## 그림 바꾸기

투명 PNG, 사각형 잘림 영역, 다른 내용과 겹친 그림을 원래 그리기 순서로 교체합니다. RGB 교체는 원래 투명 마스크를 유지하고 RGBA 교체는 새 이미지의 투명도를 사용합니다. 공유된 이미지도 고른 위치만 바뀝니다. 원래 회전·기울임과 복잡한 클립도 유지합니다. 투명 그림이 렌더링 경로를 바꾸는 경우에는 불투명 대조본과 비교하며, 주변의 실제 변경은 계속 검사합니다.

## 팀 하네스 사용하기

팀 서랍에서 하네스를 열고 **사용**을 누르면 해당 RED 또는 BLUE 화면에 선택됩니다. BLUE Evidence v0.3.5는 연결된 PC의 실행 경로에 맞춰 준비됩니다. 실행 소스는 별도 사본으로 보관되어 이후 앱 업데이트가 그 사본을 바꾸지 않습니다. 하네스를 고르는 단계에서는 모델을 실행하지 않습니다.

실패 화면은 실패한 실행의 하네스와 원인을 표시합니다. 알려진 실패는 실행 버튼으로 다시 시도할 수 있고, 접수 여부가 불명확한 요청은 먼저 조회합니다. 원래 요청과 진단 파일은 접힌 메뉴에 있습니다.

## 시도 기록과 비교

결과 기록에 완료·실패·취소·상태 미확인을 남깁니다. 하네스 버전, 입력 해시, 요청 모델과 설정, 관찰 시간, 보고된 호출 수를 보관합니다. 비용이나 호출 수를 받지 못하면 미상으로 표시합니다. 기존 성공 응답과 사람 검수는 별도로 유지합니다.

**팀에 공개**를 누르면 고른 시도 메타데이터를 Confluence에 보관합니다. 팀에서 연 기록은 12시간 동안 임시 열람하며 로컬 이력에 합치지 않습니다. 비교에는 같은 입력·모델·예산 등의 조건과 매개변수 차이, 사람 검수 메모를 표시합니다.

## 검증

- 기존 앱 검사와 Python 631개 검사 통과(환경별 6개 제외).
- 실제 브라우저에서 문단·선택 단어 수정, 쪽 이동, 입력 취소, 재조판 생성과 미리보기·다운로드 바이트 일치를 검사했습니다.
- 합성 기록으로 1280px·390px 비교 화면과 실패 이력, 명시적 팀 공개 동작을 검사했습니다.
- 실제 찬물 샤워 논문은 8개 변경을 포함해 내용 검사를 통과했습니다. 36쪽 사례는 40쪽으로 재조판됐고 23곳의 문자 표현 차이(µ 표기와 선택적 하이픈)를 별도로 기록합니다. 재조판은 원본 출판 레이아웃의 복제 기능과 구분됩니다.

## falsify-cover.png

생성 이미지를 바탕으로 손을 봐서 만들었다. 담긴 것은 다음과 같다.

- 워드마크 FALSIFY. i 위의 체크 표시와 A 안의 펜촉
- 문구 두 줄. `FAKE PAPERS. REAL TESTS.` 와 `Pseudo Lab | Season 13`
- 방패와 붉은 창. Blue가 막고 Red가 뚫는 구도
- 방패 안에 일부러 어긋나게 넣은 두 수치. 위 칸 흰색 0.12, 아래 칸 빨간색 0.42와 가위표.
  결함 유형 D1 숫자 불일치를 그림으로 보인 것이다

수치 두 줄은 Pretendard Bold로 직접 조판해 얹었다. 소수점 자리를 두 줄에 맞췄고,
색은 원본 이미지에서 뽑은 RGB 237, 70, 71을 썼다. 생성 모델이 만든 좌우 반전 글자를
모두 지우고 그 자리를 주변 배경으로 메운 뒤에 그렸다.

고치려면 `_archive/falsify-cover-source.png` 에서 다시 시작하면 된다.

## falsify-logo.png

방패 안의 음각 F와 주황색 창을 결합한 가로형 로고다.
잉크 네이비 #12273C 와 주황 #D25B01. 배경이 투명해 밝은 바탕에서 쓴다.
어두운 바탕에 사용할 때는 밝은 색상 버전이 필요하다.

## 작업용 원본

생성 원본과 채택하지 않은 대안본은 `_archive/`에 두었고 **저장소에는 올리지 않는다**(`.gitignore`).
표지를 다시 손볼 때는 그 폴더의 `falsify-cover-source.png`에서 시작한다.
정사각 대안본 두 장(`falsify-square-paper.png`, `falsify-square-people.png`)에는
`0.12`와 `0.42`가 어긋난 표로, `[Smith et al., 2023]`이 없는 인용으로,
돋보기 안 가위표와 체크와 물음표가 라벨 세 개로 들어가 있다. 슬라이드나 포스터에 쓸 만하다.

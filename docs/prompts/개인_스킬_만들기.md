# 프롬프트를 개인 스킬로 만들기

Claude Code, Codex, Cursor 같은 에이전트 도구를 쓰는 분을 위한 한 장입니다. 안 하셔도 됩니다. 웹 챗봇에 프롬프트를 붙여 넣는 것으로 충분합니다.

이 폴더의 프롬프트를 자기 도구의 스킬이나 규칙 파일로 옮기면, 매번 복사하지 않고 "이 논문에 D1 심어 줘" 한 줄로 돌릴 수 있습니다. 이런 식으로 만들어 **자기 환경에 맞게 고쳐 쓰세요.**

## 공통 원리

스킬은 프롬프트에 둘을 더한 것입니다. (1) 언제 쓰는지 한 줄 설명. (2) 입력을 어디서 받고 출력을 어디에 둘지.

```
skills/falsify-red/SKILL.md     ← 프롬프트 본문 + 설명
```

본문은 `red_제출.md`의 코드 블록을 그대로 넣고, 맨 위에 설명을 붙이고, `[유형]`과 `(여기에 논문 마크다운)` 같은 자리를 "사용자가 준 인자"로 바꾸면 됩니다.

## Claude Code

`~/.claude/skills/falsify-red/SKILL.md`를 만듭니다.

```markdown
---
name: falsify-red
description: Falsify 스터디의 Red. 논문 마크다운 경로와 결함 유형(D1~D4)을 받아 결함 하나를 심고 패치를 만든다
---

(red_제출.md의 코드 블록을 여기에. [유형]은 인자로, 논문은 경로를 읽어서)

출력은 submissions/wN/<팀>/<paper-id>.diff 와 정답지 JSON으로 저장한다.
```

그 뒤 `/falsify-red corpus/raw/PMC12215570.md D1` 처럼 부릅니다. Blue도 같은 식으로 `falsify-blue`를 만들고, 자가 판정 루프는 두 스킬을 번갈아 부르는 것입니다.

## Codex

저장소 루트나 홈의 `AGENTS.md`에 절을 더합니다.

```markdown
## Falsify Red
"red <논문경로> <유형>"이라고 하면 docs/prompts/red_제출.md의 지시대로 결함 하나를 심고 패치를 submissions/에 저장한다.
```

Codex는 `AGENTS.md`를 자동으로 읽습니다. 프롬프트 파일을 복사하지 않고 경로로 가리켜도 됩니다.

## Cursor

`.cursorrules` 또는 `.cursor/rules/falsify.md`에 같은 내용을 넣습니다.

## 자동 루프를 만들고 싶으면

Red 3회 자가 판정은 셸 스크립트로 묶을 수 있습니다.

```bash
for i in 1 2 3; do
  # Red: 심기 (또는 전 회차 결과를 고치기)
  # Blue: 다른 모델로 판정
  # 잡혔으면 계속, 안 잡혔으면 멈춤
done
```

이것이 선택 트랙 T1(Red 자동화)의 출발점입니다. 7주차부터 같이 만듭니다.

## 지킬 것

- 스킬 안에서도 **Blue에 원본을 주지 않습니다.**
- 정답지는 비공개 저장소로만 보냅니다. 스킬이 공개 저장소에 정답을 쓰지 않게 경로를 확인합니다.
- 반복은 3회까지. 스킬에 상한을 박아 두세요.
- 만든 스킬을 공유하고 싶으면 💡 아이디어 이슈에 올려 주세요. 쓸 만하면 이름을 붙여 저장소에 넣습니다.

# 프롬프트 모음

어떤 AI 도구를 쓰든 참여할 수 있게 만든 복사용 프롬프트입니다. ChatGPT, Claude, Gemini 같은 웹 챗봇에 붙여 넣으면 이슈 양식에 맞는 결과가 나옵니다.

**막히면 혼자 붙들지 말고 🙋 이슈나 카톡에 올려 주세요. 같은 데서 막히는 분이 대개 더 있습니다.**

| 단계 | 누구 | 하는 법 |
|---|---|---|
| 1. 웹 챗봇으로 끝내기 | 모두 | 이 폴더의 프롬프트를 복사해 붙입니다. 논문은 웹에서 받습니다. **이것만 해도 시즌 전체를 완주할 수 있습니다** |
| 2. 스크립트로 하기 | 파이썬 되는 분 | `tools/` 폴더의 스크립트. `tools/README.md` |
| 3. 에이전트로 자동화 | Claude Code, Codex, Cursor 쓰는 분 | 프롬프트를 개인 스킬로 옮깁니다. [개인_스킬_만들기.md](개인_스킬_만들기.md) |

올라가는 것은 본인이 정합니다. 1단계만 해도 아무 불이익이 없습니다.

## 10분 버전

시간이 없는 주에는 각 프롬프트의 "짧게 하려면" 절만 하셔도 제출로 셉니다. 한 줄만 바꾸는 Red, 유형 하나만 보는 Blue입니다.

## 반복은 3회까지

AI를 쓰면 심고, 돌려 보고, 고치는 루프가 돕니다. 막지 않습니다. 다만 주당 3회까지만 하고 회차마다 무엇을 바꿨는지 한 줄 적어 주세요. 같은 모델이 자기 결과를 거듭 고치면 오히려 나빠진다는 보고가 있고, 그 기록 자체가 연구 데이터입니다.

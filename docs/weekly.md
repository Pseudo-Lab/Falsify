## 모임 2시간

| 시간 | 무엇 |

| 0~18분 | 팀별 2분 "이번 주 한 줄". 낸 것, 잡힌 것, 막힌 것 |
| 18~26분 | 노하우 미니 발표 8분. "내 분야에서는 이렇게 잡는다" |
| 26~50분 | 발표 두 팀, 각 12분 |
| 50~60분 | 지난주 집계와 다음 수. 논문마다 승급인가 재방어인가 |
| 60~105분 | 라이브 매치. 전원 노트북을 켜고 그 자리에서 Red 또는 Blue |
| 105~117분 | 마무리 한마디. 전원 1분. GitHub 스레드에 댓글 한 줄 |
| 117~120분 | 다음 주 할 일 |

모임 15분 전(20:45)부터 열린 질문 시간입니다. 오고 싶은 분만.

## 제출물

| 역할 | 어디에 | 무엇 |
|---|---|---|
| Red | `submissions/wN/<팀>/` | 패치(`.diff`). 1차와 최종 둘 다 |
| Red | 비공개 저장소 `Falsify-keys` | 정답지 JSON |
| Red | 🔴 이슈 | 위치, 왜 놓치기 쉬운가, 어떻게 잡나, 반복 횟수. "무엇을 바꿨나"는 Blue 주차 뒤에 |
| Blue | `results/wN/<팀>.csv` | 판정 행 |
| Blue | `results/wN/<팀>/transcript.md` | 프롬프트와 출력 |
| Blue | 🔵 이슈 | 잡은 것, 못 잡은 것, 오탐 |
| 전원 | `[WN] 마무리 한마디` 스레드 | 댓글 한 줄 |

## 최소선

매주 셋이면 됩니다. 이번 주 한 줄, 제출 1회, 마무리 한마디. 10분 버전도 제출입니다. 지난 주 것은 안 해도 됩니다. 이번 주 것만 하면 복귀입니다.

## 쉬어 가기

카톡에 "이번 주 쉬어 갑니다" 한 줄이면 됩니다. 이유를 안 적어도 됩니다. 몇 주 동안 제출 없이 모임만 오셔도 됩니다. 돌아오고 싶을 때 말씀해 주세요.

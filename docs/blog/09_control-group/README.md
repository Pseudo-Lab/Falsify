# 대조군이란 무엇일까? — '다 잡았다'는 착각 피하기

![cover](cover.png)

> 작성: 이건규 · 게시: 2026-11-02 · 가짜연구소 Falsify 자료 탭


## 이 글은 AI로 초안을 작성하고 사람이 검토했습니다!

AI 검토 도구에 거짓 문장 24개를 넣었더니 24개 모두 걸렸습니다. 탐지 성공일까요?

Falsify에서 실제로 있었던 일입니다. 처음에는 전부 잡았다고 생각했습니다. 그런데 이 결과는 아무 문장에나 낮은 점수를 주는 도구에서도 똑같이 나옵니다. 참인 문장을 함께 넣어 보고 나서야, 그 도구가 참과 거짓이 아니라 다른 것을 보고 있었다는 사실을 알았습니다.

이번 글에서는 이런 착각을 막는 가장 단순한 장치인 **대조군**을 다룹니다. 앞선 글처럼 ChatGPT나 Claude의 새 채팅과 기록표만으로 실습합니다. 코딩은 필요 없습니다.

> 이 글의 Falsify 수치는 김가경 님의 「탐지기를 측정한 4주와 빌런나이트 발표」(2026.10.29)에서 가져왔습니다. 특정 클라우드 기능 하나를 측정한 결과이므로, 모든 근거 확인 도구가 같은 방식으로 동작한다는 뜻은 아닙니다.

## 1. 대조군이 무엇인가요?

대조군은 **결과를 비교할 기준이 되는 묶음**입니다.

약의 효과를 볼 때 약을 먹은 사람만 보면, 나아진 이유가 약 때문인지 시간이 지나서인지 알 수 없습니다. 약을 먹지 않은 사람을 함께 보아야 차이를 말할 수 있습니다.

AI 검토 도구도 같습니다.

| 넣은 것 | 알 수 있는 것 |
|---|---|
| 거짓 문장만 | 거짓 문장에 어떤 반응을 보였는가 |
| 거짓 문장 + 참 문장 | 거짓과 참을 **구분**했는가 |
| 거짓·참 문장 × 근거에 있음·없음 | 도구가 참/거짓을 보는지, 다른 것을 보는지 |

거짓 문장만 넣으면 '걸린 개수'는 셀 수 있지만 '구분했는지'는 알 수 없습니다.

## 2. "다 잡았다"가 착각이 되는 구조

아래 두 도구가 있다고 생각해 보세요.

| | 거짓 문장 24개 | 참 문장 24개 |
|---|---|---|
| 도구 A | 24개 모두 낮은 점수 | 24개 모두 높은 점수 |
| 도구 B | 24개 모두 낮은 점수 | 24개 모두 낮은 점수 |

거짓 문장만 넣었다면 두 도구의 결과는 같습니다. 둘 다 "24개 다 잡았다"입니다. 참 문장 칸이 있어야 도구 B가 아무것도 구분하지 못한다는 사실이 드러납니다.

대조군을 넣으면 내 결과가 무엇을 말해 주는지 알 수 있습니다. 도구를 못 믿어서 하는 일은 아닙니다.

## 3. Falsify에서 실제로 본 것

Falsify 팀은 클라우드의 근거 확인 기능을 188회 호출해 측정했습니다. 근거 글과 검사할 문장을 넣으면 0~1 점수를 돌려주는 기능입니다.

| 넣은 문장 | 실제로 | 근거 글에 들어 있음 | 점수 |
|---|---|---|---|
| 논문의 참인 문장 | 참 | 예 | 0.97 |
| 논문의 참인 문장 | 참 | 아니요 | 0.07 |
| 연구팀이 심은 거짓 문장 | 거짓 | 예 | 0.99 |

첫 줄과 둘째 줄은 둘 다 참인 문장인데 점수가 크게 갈렸습니다. 다른 점은 근거 글에 들어 있었는지 하나입니다. 셋째 줄은 거짓 문장인데도 근거 글에 들어 있으니 0.99가 나왔습니다.

이 측정에서 점수는 '참인가'가 아니라 '**근거 글에 들어 있는가**'를 따라갔습니다.

처음 본 "심은 문장 24건이 모두 걸렸다"는 결과도 이렇게 다시 읽힙니다. 심은 문장은 원래 근거 글에 없는 문장이니 낮은 점수가 나온 것이고, 근거 글에 없는 참인 문장도 마찬가지로 낮은 점수를 받았습니다. 팀은 측정보다 대조 실험에 두 배의 노력을 들였고, 결론은 대조 실험에서 나왔습니다.

## 4. 쓸모가 없다는 뜻은 아닙니다

같은 기능이 잘 맞힌 과제도 있었습니다.

| 과제 | 결과 |
|---|---|
| 논문이 인용한 문헌이 실제로 근거 글에 있는지 확인 | 45건 중 45건 정확 |
| 숫자만 바꾼 문장 찾기 | 20건 중 6건만 걸림 |

'포함 여부'를 보는 도구는 없는 인용을 찾는 데에는 맞고, 숫자 오류나 모순을 찾는 데에는 맞지 않습니다. 대조군 결과를 보면 이 도구를 어떤 일에 쓸지 정할 수 있습니다.

## 준비물과 이번에 만들 것

- ChatGPT 또는 Claude에서 새 채팅을 열 수 있는 환경
- 메모장이나 Markdown 편집기
- 결과를 적을 표 (스프레드시트나 문서 표면 충분합니다)

이번 목표는 **문장 카드 네 장으로 AI 검토의 반응을 비교하는 2×2 대조 실험**입니다. 하네스 글에서 만든 기록 방식을 그대로 이어 씁니다.

## STEP 1. 무엇을 재는지 한 문장으로 적습니다

대조 실험은 질문이 분명해야 설계할 수 있습니다.

```
이번에 재는 것:
AI 검토가 "문장이 근거 글에 들어 있는가"와 "문장이 사실과 맞는가"를 구분하는가.
```

질문이 "AI가 잘 검토하는가"처럼 넓으면 어떤 대조군이 필요한지 정할 수 없습니다.

## STEP 2. 근거 글 두 개를 준비합니다

앞선 글들의 공통 예제를 그대로 씁니다. 다만 이번에는 근거 글을 두 버전으로 만듭니다.

```
근거 E01 (원본):
계획한 대상자는 10명이었다. 이 중 8명에게 결과를 제공했고 2명은 보류했다.
```

```
근거 E01-X (거짓 문장이 섞인 버전):
계획한 대상자는 10명이었다. 계획한 10명 전원에게 결과를 제공했다.
```

E01-X는 일부러 틀리게 만든 근거입니다. 실제 업무에서도 근거로 받은 문서 자체에 오류가 섞여 있을 수 있습니다.

## STEP 3. 문장 카드 네 장을 만듭니다

| 카드 | 검사할 문장 | 함께 줄 근거 | 실제로 | 근거에 들어 있음 |
|---|---|---|---|---|
| C1 | 10명 중 8명에게 결과를 제공했다. | E01 | 참 | 예 |
| C2 | 2명은 보류했다. | E02 (아래) | 참 | 아니요 |
| C3 | 계획한 10명 전원에게 결과를 제공했다. | E01-X | 거짓 | 예 |
| C4 | 계획한 10명 전원에게 결과를 제공했다. | E01 | 거짓 | 아니요 |

```
근거 E02:
계획한 대상자는 10명이었다.
```

'실제로' 칸은 사람만 압니다. 이 표는 AI에게 보여주지 않고 따로 보관하세요. 하네스 글에서 정답표를 입력과 분리한 것과 같은 원칙입니다.

## STEP 4. 질문을 두 종류로 준비합니다

같은 카드를 두 가지 방식으로 물어봅니다.

**질문 A: 점수만 받기**

```
아래 문장이 제공된 근거와 얼마나 일치하는지 0~1 점수로만 답해줘.
설명은 쓰지 마.

근거: (근거 붙여넣기)
문장: (문장 붙여넣기)
```

**질문 B: 두 질문을 나눠 받기**

```
너는 주장과 근거를 대조하는 검토 도우미다.
제공한 근거만 사용하고, 웹 검색이나 외부 자료는 쓰지 않는다.

아래 두 가지를 따로 답한다.
1. 포함: 문장의 내용이 근거에 적혀 있는가? (예 / 아니요 / 일부)
2. 판정: 근거가 이 문장을 지지하는가? (맞음 / 아님 / 확인 필요)
   - 맞음: 근거가 문장을 지지한다.
   - 아님: 근거와 충돌한다.
   - 확인 필요: 근거가 부족해 판단할 수 없다.
3. 근거 인용: 판단에 쓴 문장을 짧게 인용한다.
4. 한계: 이 근거만으로 알 수 없는 것을 적는다.

근거: (근거 붙여넣기)
문장: (문장 붙여넣기)
```

질문 B의 4번 '한계' 칸은 근거에 적혀 있다는 것과 사실이라는 것이 서로 다른 질문임을 AI와 나 모두에게 남겨 둡니다.

## STEP 5. 카드마다 새 채팅에서 실행합니다

카드 4장 × 질문 2종이면 8회입니다. 회차마다 새 채팅을 열고, 원응답을 그대로 저장하세요.

| 회차 | 카드 | 질문 | 점수 | 포함 | 판정 | 원응답 위치 |
|---|---|---|---|---|---|---|
| 1 | C1 | A | | | | |
| 2 | C1 | B | | | | |
| ... | | | | | | |

아직 실행하지 않은 칸은 비워 두세요. 예상값을 미리 채우면 실제 결과와 섞입니다.

## STEP 6. 2×2로 놓고 읽습니다

기록이 끝나면 카드를 네 칸에 놓아 봅니다.

| | 근거에 들어 있음 | 근거에 없음 |
|---|---|---|
| **참** | C1 | C2 |
| **거짓** | C3 | C4 |

이렇게 읽으세요.

- **점수가 왼쪽 열(C1, C3)에서 높고 오른쪽 열(C2, C4)에서 낮다면**, 점수는 참/거짓보다 포함 여부를 따라가고 있을 가능성이 큽니다. Falsify의 측정과 같은 모양입니다.
- **C3에서 '맞음'이 나왔다면** 이상한 일이 아닙니다. 주어진 근거만 보면 지지되기 때문입니다. 대신 '한계' 칸에 "근거 자체가 맞는지는 알 수 없다"는 취지가 있는지 보세요.
- **C2에서 '아님'이 나왔다면** 근거가 없다는 것을 틀렸다는 것으로 바꿔 읽은 것입니다. '확인 필요'가 기대하는 답입니다.
- **C4만 보고 "거짓을 잡았다"고 하면** 이 글 처음의 착각과 같습니다. C2와 함께 보아야 합니다.

> 위 해석은 설명용 기대 패턴이며 실제 모델 실행 결과가 아닙니다. 카드 네 장으로는 도구의 일반 성능을 말할 수 없습니다.

## STEP 7. 확인한 범위만 결론에 씁니다

결론 문장도 대조 실험의 범위를 넘지 않게 씁니다.

| 넘어선 결론 | 범위 안의 결론 |
|---|---|
| 이 도구는 거짓 문장을 잘 잡는다. | 근거에 없는 문장에 낮은 점수를 주었다. 근거에 없는 참 문장에도 낮은 점수를 주었다. |
| 이 도구는 쓸모없다. | 카드 4장에서 점수는 포함 여부와 함께 움직였다. 인용 확인처럼 포함 여부를 묻는 일에는 다시 시험해 볼 수 있다. |

## 자주 헷갈리는 질문

**대조군은 몇 개나 있어야 하나요?**
정해진 숫자는 없습니다. 먼저 "무엇과 무엇을 구분하는지"를 보여줄 칸을 하나씩 채우는 것이 우선입니다. 이번 실습에서는 2×2의 네 칸입니다.

**정답을 아는 문제만 넣어도 대조군인가요?**
정답을 아는 것과 대조군은 다릅니다. 정답을 아는 거짓 문장만 넣으면 '걸린 수'만 볼 수 있습니다. 참 문장, 근거에 없는 문장처럼 **다른 이유로 같은 결과가 나올 수 있는 문장**을 함께 넣어야 대조가 됩니다.

**점수가 높으면 그래도 참일 가능성이 높지 않나요?**
이번 측정에서는 근거에 들어 있는 거짓 문장이 0.99를 받았습니다. 점수가 무엇을 따라가는지 대조군으로 확인하기 전에는 점수를 참일 확률로 읽지 마세요. Jev 글에서 확률과 confidence를 구분한 것과 같은 이유입니다.

## Falsify 실습에서는 이렇게 써보세요

- 탐지 결과를 볼 때 **심은 결함만** 세지 말고, 원본 논문에서 고른 **참인 문장 몇 개**를 같은 방식으로 함께 돌려 보세요.
- 근거 확인 도구를 쓴다면 근거 글에 문장이 들어 있는 경우와 없는 경우를 나눠 기록하세요.
- 공동 기록표에 '대조 카드' 열을 하나 만들어, 어떤 회차가 대조군이었는지 표시해 두세요.
